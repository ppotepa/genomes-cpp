11. TERRAIN
======================================================================

SOURCE terrain keeps one authoritative mutable height field.

Road/pad grading writes the authoritative heights and then updates render
geometry/normals.

Routine getHeightAt/sample reads the same height field in O(1).

Cell interpolation uses the explicit diagonal:
    u + v <= 1
        triangle (a,d,b)
    else
        triangle (c,b,d)

This convention is part of numeric parity fixtures.
