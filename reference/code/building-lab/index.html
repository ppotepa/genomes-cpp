Podgląd konstrukcji

Schody nie są dekoracją: manifest zawiera ich szerokość, wysokość i linię przejścia między kondygnacjami. To jest punkt zaczepienia dla późniejszego navmesha/jednostek.

Destrukcja — makieta

Ściany, szyby, ramy, drzwi, stropy, dach i schody mają osobne identyfikatory, typ materiału, HP i flagę nośności. Tu element jest tylko ukrywany po zniszczeniu; później można podpiąć gruz, fizykę i propagację podpór.
