PIPELINE
========
unitSeed -> istniejący InfantryGenome -> phenotype -> anatomia -> szkielet
                                                     -> powierzchnia ciała
unitSeed -> hash EQUIPMENT/v1 -> equipmentSeed -> profil + override -> Equipment
                                   -> EquipmentFit(anatomia, ubranie, sloty)
                                   -> proceduralna geometria wyposażenia

FINALNY MODEL
=============
model.root
  hips -> istniejąca hierarchia 39 kości
  InfantrySurface: SkinnedMesh, ubranie / skóra / włosy / twarz
  InfantryEquipment: SkinnedMesh, wyposażenie podpięte do TEGO SAMEGO skeletonu

Przedmioty sztywne mają wagę 1 do właściwej kości; szelki i elastyczne panele
mają mieszane wagi. Nie tworzymy osobnego szkieletu dla plecaka/hełmu.
Sprzęt jest budowany we współrzędnych pozy referencyjnej w metrach, następnie
wiąże się z istniejącą macierzą bind, nawet gdy żołnierz aktualnie kuca.

NIEZALEŻNOŚĆ DANYCH
==================
R.Unit posiada Equipment niezależnie od category/type. Przyszły pojazd
przekazuje własny slotSchema i własny renderer; nie dziedziczy anatomii człowieka.
InfantryUnit extends Unit i przekazuje 20 slotów opisanych w EquipmentSlots.
Rola piechoty jest wyłącznie profilem loadoutu. Nie tworzy nowej klasy ani genomu.

WYMIANA GEOMETRII
================
setEquipment buduje nowe bufory przed zastąpieniem starych. Błąd generatora
zachowuje poprzedni model. Nie wymienia skeletonu, genomu ani animatorów.
W podglądzie kamera, faza, pause, mimika i czas rozglądania zostają zachowane.
Zmiana anatomii w edytorze genomu przebudowuje jednostkę, ale zachowuje dane gear.

ZASOBY
======
Geometria jest własnością modelu i jest dispose() przy podmianie/usunięciu.
Materiały ciała i gear są współdzielone w świecie. Podgląd klonuje materiały
wyłącznie do trybu wireframe. Jego klony zwalnia UnitPreview, materiały wspólne
zwalnia Game przy zakończeniu. Dane Equipment nie zawierają obiektów Three.js.

DODATEK 0.11
GroundContact (js/animation/groundContact.js) jest własnością animatora.
Przechowuje punkt w świecie i lokalny punkt podparcia. Nie jest komponentem
fizyki ani genomu. Unit steruje prędkością demo i mapowaniem move/rest.
