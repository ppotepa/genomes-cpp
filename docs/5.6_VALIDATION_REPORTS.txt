======================================================================
PUBLIC CONTRACTS
======================================================================
1. ValidationSeverity = Info, Warning, Error, Fatal. Only Error/Fatal make artifact invalid by default; policy may promote warnings in tests.

2. ValidationCode is stable domain-specific numeric/string ID. Human message is not used for machine decisions.

3. ValidationIssue may carry artifact/node ID, semantic object ID, world bounds/position and key-value diagnostics.

4. ValidationReport preserves stable issue order: by phase, stable object key, code.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.

PSEUDOCODE
======================================================================
VALIDATE ARTIFACT:
    report := validator.validate(artifact)
    stableSort(report.issues, phase/object/code)
    if report.hasError:
        return Failure(ValidationFailed, report)
    return Success(report)

MERGE:
    for issue in child:
        copy := issue
        copy.context.prepend(parentContext)
        parent.add(copy)
