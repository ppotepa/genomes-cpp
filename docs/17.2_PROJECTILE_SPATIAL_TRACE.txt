======================================================================
PUBLIC CONTRACTS
======================================================================
1. BallisticsWorld advances projectiles at fixed simulation tick with strategy-selected aerodynamic integration and bounded adaptive substeps based on travel distance/contact risk. Projectile remains persistent across obstacles until stopped/detonated/ground/limit.

2. Trace broadphase combines WorldQuery static BVH/building logical structural index, dynamic physics/body spatial index, target damage geometry and RubbleField tiles. Candidates are sorted by swept distance/t with stable semantic tie-break; broadphase candidate is rechecked against actual geometry.

3. Moving target bounds include linear swept extent over dt and, where necessary, conservative angular/shape bounds. Physics snapshot provides target motion state for relative contact input.

4. Ground is semantic Terrain/Rubble surface provider; projectile crossing from above to below surface emits actual intersection GroundContact. No arbitrary horizontal ground extent. If no ground/provider or no contact before configured age/travel limit, end TrackingLimit.

5. Material traversal uses logical Solid/Assembly geometry, not only physics collider, so holes/damage/air gaps and physicalSolidId interfaces remain authoritative.

======================================================================
DATA LAYOUT
======================================================================
Active projectile SoA/chunks plus per-projectile small contact/trace query state. Broadphase candidate buffers are ScratchContext-owned. Trace history/presentation recorder is separate diagnostic subsystem, not required for simulation.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define BallisticsEnvironment gravity/air density/wind/ground provider/tracking limits and fixed-step integration contract.

STEP 2
    Implement strategy aerodynamic integration with full velocity/orientation; isolate numerical integrator version. Start with semi-implicit/RK scheme matching SOURCE fixture tolerance.

STEP 3
    Compute swept segment for substep and query broadphase candidates from region/world indexes, rubble and dynamic targets. Do not scan all solids.

STEP 4
    Narrow-phase candidates against current logical geometry/material assembly and choose nearest valid hit by t then stable semantic ID.

STEP 5
    Advance projectile to hit point, call ImpactSolver/strategy, preserve residual projectile/contact state, then continue remaining substep/travel if penetrated/ricocheted; cap contacts/substep and record explicit limit.

STEP 6
    Implement ground intersection and tracking-limit terminal states.

STEP 7
    Add moving-target swept-bound test, sequential walls, holes, rubble and render OFF/ON independence fixture.

======================================================================
PSEUDOCODE
======================================================================
FIXED STEP projectile:
    strategy.aerodynamicStep(state, dt)
    timeRemaining := dt
    contacts := 0

    while timeRemaining > 0 and state.flightActive:
        subdt := chooseBoundedSubstep(state,timeRemaining)
        from := state.position
        predicted := integratePosition(state,subdt)

        candidates := broadphaseSwept(from,predicted,subdt)
        hit := nearestActualHit(candidates, from,predicted)

        groundHit := terrain/rubble surface crossing
        choose nearest hit/ground event

        if none:
            state.position := predicted
            state.travel += distance(from,predicted)
            timeRemaining -= subdt
            continue

        advance exactly to hit fraction/time
        if ground: finish GroundContact
        else:
            impactResult := impactSolver.step(...)
            emit damage/physics commands
            apply result to projectile
            if penetrated/ricochet: continue remaining time
            else finish stopped/detonation candidate

        if ++contacts > maxContactsPerStep:
            finish/contact-limit diagnostic

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Projectiles partition into jobs. Each job reads immutable world/physics query snapshots and writes projectile states + thread-local impact commands. Target damage commits happen after trace batch, then world logical index rebuild once per target/batch.

======================================================================
ERROR HANDLING
======================================================================
Spatial query PartialUnloaded obeys policy: active combat regions should be pinned; unknown required geometry causes Deferred/RegionUnavailable rather than tracing through empty unknown space. Contact/substep caps record explicit diagnostic.

======================================================================
DETERMINISM RULES
======================================================================
Candidate sort t + stable semantic ID. Fixed-step state and deterministic target snapshot. Parallel projectile completion does not define damage commit order.

======================================================================
PERFORMANCE RULES
======================================================================
Spatial broadphase, swept BVH, batch projectile jobs, reuse scratch. Benchmark 1k/10k/100k projectiles and dense building/rubble scenes.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Port SOURCE behavior and acceptance scenarios while replacing JS all-object scans. Trace presentation compression moves to separate diagnostic/presentation service.
