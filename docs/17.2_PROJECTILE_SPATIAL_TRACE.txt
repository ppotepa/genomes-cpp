======================================================================
PUBLIC CONTRACTS
======================================================================
1. BallisticsWorld advances on authoritative fixed tick. FireRequest includes stable id/weapon/ammo/position/direction/tick/seed and is validated before queueing.

2. Flight acceleration uses explicit Environment{wind,density,gravity,soundSpeed}; no camera dependence. Integration method and constants are versioned.

3. Adaptive flight interval is bounded by remaining fixed step, maximum travel distance and curvature/chord error. Continuous segment query prevents tunneling through thin materials.

4. WorldQueryService returns sorted semantic hits across static/dynamic/rubble/terrain sources. Ballistics does not know renderer or Jolt object pointers.

5. Terminal reasons are explicit enum including GroundContact, TrackingLimit, Stopped, Detonated, Removed/Capacity; tracking timeout is not a fake physical collision.

6. ProjectileTrace semantic/debug recorder is optional observer. Diagnostic failure never alters projectile simulation.

======================================================================
DATA LAYOUT
======================================================================
Ballistics storage uses packed active arrays plus pending fire queue. Trace history is separate bounded diagnostic store keyed by shot/trace IDs. SegmentHit contains t/distance, point, normal, SemanticPartId/material assembly ref and target motion snapshot.

PSEUDOCODE
======================================================================
FIXED STEP:
    flush pending fire requests in stable enqueue sequence
    for projectile batch:
        remaining := fixedDt
        while remaining > 0 and projectile.alive:
            dt := chooseFlightInterval(projectile, remaining, environment)
            predicted := integrateRK4(state.p, state.v, dt)
            hit := worldQuery.segmentSweep(state.p, predicted.p, radius)
            if hit:
                advance exactly to hit fraction/time
                emit ContactCandidate
                resolve contact
            else:
                ledger.flightWork += deltaTranslationalEnergyDueToEnvironment(...)
                state := predicted
                age += dt
                travel += segmentLength
            remaining -= consumedDt

RK4:
    a1 := acceleration(v)
    v2 := v + a1*dt/2
    a2 := acceleration(v2)
    v3 := v + a2*dt/2
    a3 := acceleration(v3)
    v4 := v + a3*dt
    a4 := acceleration(v4)
    p2 := p + dt/6 * (v + 2v2 + 2v3 + v4)
    vOut := v + dt/6 * (a1 + 2a2 + 2a3 + a4)

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Active projectile chunks can integrate/query in parallel against immutable world query snapshot. Contacts/events stored per-job then stable-merged. Structural mutations occur after ballistics commit.

======================================================================
ERROR HANDLING
======================================================================
Fire validation returns explicit rejection. Nonfinite integration state kills projectile with diagnostic terminal reason. Query failure is simulation error, not treated as no-hit.

======================================================================
DETERMINISM RULES
======================================================================
Fire requests ordered by tick + stable sequence/ID. Same world snapshot and worker count changes must yield same semantic hit ordering; stable hit tie-break by t then semantic ID.

======================================================================
PERFORMANCE RULES
======================================================================
Broadphase avoids all-solid scans. Adaptive substeps cap travel/chord error. Benchmark 1k/10k/100k flight steps and hit-rich scenarios.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Preserve SOURCE trace semantics/version in exported fixtures; native renderer for traces comes later as debug presentation.
