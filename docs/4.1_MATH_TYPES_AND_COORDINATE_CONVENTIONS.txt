======================================================================
PUBLIC CONTRACTS
======================================================================
1. Vec2 represents abstract 2D; planar world helpers use XZ-named accessors/types where ambiguity matters. Vec3 is float for local runtime/render/physics data; double variants are explicit Vec3d for global calculations.

2. Transform = translation + normalized quaternion rotation + nonuniform scale; semantic composition follows DATA-MATRIX-001. No renderer-specific matrix convention leaks into engine math.

3. Angle APIs use radians only; Degree wrapper is allowed only for UI/import conversion.

4. Floating comparisons are explicit helpers nearEqual(a,b,absTol,relTol); operator== remains exact component equality.

======================================================================

PSEUDOCODE
======================================================================
TRANSFORM POINT:
    pScaled := p * scale
    pRotated := rotate(rotation, pScaled)
    return translation + pRotated

COMPOSE parent, local:
    out.scale := parent.scale * local.scale
    out.rotation := normalize(parent.rotation * local.rotation)
    out.translation := parent.translation + rotate(parent.rotation, local.translation * parent.scale)

SAFE NORMALIZE:
    l2 := dot(v,v)
    if l2 <= threshold*threshold: return Error(Degenerate)
    return v / sqrt(l2)
