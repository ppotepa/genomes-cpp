======================================================================
PUBLIC CONTRACTS
======================================================================
1. Residency dimensions are independent: Semantic, Simulation, Render, Physics, Navigation. Region is not one boolean loaded flag.

2. Streaming request reason/priority is explicit: camera presentation, simulation relevance, path corridor, combat, preload, persistence. Camera must not unload authoritative active combat state.

3. Load/generate/compile jobs are cancellable and commit region representations by artifact/revision only when complete.

4. Dormant distant simulation may aggregate/reduce cadence but semantic state persists. Re-entry reconstructs representation without rerolling RNG/identity.

5. Memory budgets drive eviction by representation class with stable policy and pin counts/readers.

======================================================================
DATA LAYOUT
======================================================================
RegionResidencyState bit/state per representation, desired/current, priority, generation, pending JobGroup, memory bytes. LRU/priority queues keyed stable region coords + last semantic access tick.

PSEUDOCODE
======================================================================
EVALUATE DESIRED:
    for region:
        desired.semantic := persistence or any consumer
        desired.simulation := active entities/combat/orders
        desired.render := camera visibility/preload
        desired.physics := simulation interactions/near
        desired.nav := path corridors/active AI

TRANSITION:
    if desired && !current:
        schedule load/compile with generation token
    if !desired && current && pinCount==0:
        schedule retire representation
    on job complete:
        if token still current and artifact revision matches:
            publish
        else:
            discard result

EVICT:
    candidates := unpinned representations sorted by policy score
    until bytes <= budget:
        retire candidate representation, preserve semantic state as required

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Streamer orchestration owns state; jobs run common pool. Publish/retire through safe barriers/handles. Renderer/physics/nav hold pins/snapshots.

======================================================================
ERROR HANDLING
======================================================================
IO/artifact failure leaves previous representation or marks region unavailable with retry/backoff; never commits partial package.

======================================================================
DETERMINISM RULES
======================================================================
Semantic generation identity unaffected by load order. Eviction/render state does not change authoritative RNG/state.

======================================================================
PERFORMANCE RULES
======================================================================
Benchmark IO/generation/compile overlap, peak memory, churn, cancellation waste, hitch percentile. Prefetch without uncontrolled working-set growth.
