======================================================================
PUBLIC CONTRACTS
======================================================================
1. ArtifactHeader contains artifact type ID, schema version, generator ID/version, root/seed identity, input fingerprint, dependency fingerprints, artifact content fingerprint, bounds/optional metadata refs.

2. Artifact payload is immutable after publication. Mutable build object is separate and converted/frozen.

3. ArtifactId is semantic/content-derived identity, not memory address.

4. ArtifactStore exposes read-only handles/views and reference-count/lifetime policy independent of renderer.

======================================================================
DATA LAYOUT
======================================================================
Prefer compact value types, contiguous hot data and explicit ownership.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define ArtifactTypeId strong ID and header schema.

STEP 2
    Define ArtifactFingerprint using separately named 128/256-bit content hash placeholder; do not misuse StableHash64 for large artifact collision assumptions. Select BLAKE3/XXH3 in 5.5 with dependency policy.

STEP 3
    Implement in-memory ArtifactStore keyed by ArtifactId/fingerprint with immutable shared ownership using intrusive/ref-count or shared_ptr only at cold artifact level where justified.

STEP 4
    Store dependency list sorted by ArtifactId for canonical serialization.

STEP 5
    Implement provenance serialization metadata to support reference fixtures.

STEP 6
    Add immutability/concurrency read tests.

======================================================================
PSEUDOCODE
======================================================================
FREEZE:
    validate builder
    canonicalPayload := serializeCanonical(builder.payload)
    fingerprint := contentHash(canonicalPayload)
    header := provenance + fingerprint
    artifact := immutable(header, move(payload))
    store.publish(artifact)

LOOKUP:
    handle := store.find(artifactId)
    return immutable view
