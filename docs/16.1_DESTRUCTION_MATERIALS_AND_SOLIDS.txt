======================================================================
PUBLIC CONTRACTS
======================================================================
1. MaterialId identifies a versioned gameplay material profile. MaterialProfile stores density, elastic/plastic/crush/fracture response parameters, porous/packing behavior, surface response categories and calibration metadata. Every value carries provenance class: measured-reference, derived, or gameplay-tuned.

2. MaterialAssembly exposes assemblyId, physicalSolidId, local MaterialFrame {origin,normal,tangent,bitangent}, ordered MaterialLayer intervals and explicit Air/Void intervals. A contiguous technical mesh split sharing one physicalSolidId does not create a new physical interface.

3. Layer interval start/end are scalar distances along MaterialFrame.normal. Traversal from opposite direction reverses encounter order but does not redefine layer locations. Undeclared gaps are treated according explicit assembly validation policy, never silently filled with material.

4. MaterialField provides bounded deterministic local variation (strength/density/porosity/etc.) sampled in material-local coordinates from a stable seed. Rotation/translation of the world object must not change local material pattern.

5. Solid/StructuralPart carries stable semantic IDs, assembly/material refs, immutable base geometry/topology, current DamageField handle/revision and dynamic representation state. Rendering/physics bodies are not the source of destruction truth.

======================================================================
DATA LAYOUT
======================================================================
Material catalog is immutable SoA/cold data. MaterialAssembly stores small ordered layer vector. MaterialField parameters are compact analytic/noise descriptors; no dense voxel field unless a later profile explicitly chooses one. Solid records reference geometry/artifact IDs and damage state by stable handles.

PSEUDOCODE
======================================================================
TRACE ASSEMBLY INTERVALS:
    localStart := dot(worldStart - frame.origin, frame.normal)
    localEnd   := dot(worldEnd   - frame.origin, frame.normal)
    direction := sign(localEnd-localStart)

    intervals := assembly.layers sorted by start
    if direction < 0:
        iterate reversed

    for layer in intervals intersecting [min,max]:
        travel := intersectionLength(segmentInterval, layer.interval)
        if layer.kind == Air/Void:
            resistance := 0
        else:
            localPoint := frame.toLocal(contactPoint)
            sampled := materialField.sample(localPoint)
            emit Traversal(layer, travel, sampled)

MATERIAL FIELD:
    key := stableHash(materialField.seed, quantized/local semantic coordinate, propertyId)
    variation := deterministicNoise(key)
    return baseProperty * boundedVariation(variation)

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Material catalogs/assemblies are immutable after publication. Solid damage mutation is staged through destruction command buffers; workers read immutable geometry/material frames and write local impact results.

======================================================================
ERROR HANDLING
======================================================================
Invalid assembly returns ValidationReport with stable codes (overlap, missing frame, negative thickness, nonfinite). Missing optional calibration data selects documented gameplay default; missing required material ID is hard error.

======================================================================
DETERMINISM RULES
======================================================================
Material sampling depends only on local coordinates, seed and material-field version. World transform, worker count and trace direction do not change intrinsic sampled material values.

======================================================================
PERFORMANCE RULES
======================================================================
Layer traversal O(layer count), normally very small. MaterialField analytic sampling avoids allocating dense fields. Spatial broadphase belongs to 17.2/physics/world indexes, not material assembly scans.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Port current SOURCE values under explicit native catalog version. Preserve legacy compatibility profiles where parity requires exact behavior; improved material models get new version IDs.
