PUBLIC CONTRACTS
======================================================================
1. TARGET fixtures record schema identity and generation inputs. Imported
reference samples additionally record provenance/evidence class but remain
diagnostic. Validation separates numeric, structural, behavioral and visual
quality; no JavaScript binary layout or sequential RNG equality is required.

2. Seeded genome/selected phenotype fields require strongest feasible parity; topology/appearance validated by invariants plus selected golden metrics/images.

3. All current Infantry tests in 0.2 map to native tests or stronger superseding case; no unowned test.

4. Parallel generation/evaluation must match 1-worker semantic outputs for deterministic artifacts/channels.

5. Passing TARGET validation makes Infantry eligible for integrated gameplay.

6. The only production schema is the canonical 69-bone rig and four TARGET
morphs. Older or unpinned images may assist manual diagnosis but cannot define
expected runtime output or create alternate rig profiles.
