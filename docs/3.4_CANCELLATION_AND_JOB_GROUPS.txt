======================================================================
PUBLIC CONTRACTS
======================================================================
1. CancelSource owns atomic cancellation state; CancelToken is copyable read-only view. Cancellation is cooperative, not thread termination.

2. JobGroup owns child-job accounting and optional CancelSource; destroying an active group requires explicit wait/cancel policy, never silent detach.

3. Cancellation does not imply semantic rollback by itself. Procedural transaction chapter owns rollback/commit.

4. Long jobs define bounded cancellation polling interval by work units, not every instruction.

======================================================================
DATA LAYOUT
======================================================================
Use compact value types, explicit ownership, contiguous storage in hot paths, and no hidden shared mutable state.

PSEUDOCODE
======================================================================
JOB:
    for chunk in work:
        if ctx.cancelToken.isCancelled():
            return Cancelled
        process(chunk)

CANCEL GROUP:
    group.cancel(reason)
    group.stopAcceptingNewJobs()
    group.wait()
    release group-owned buffers
