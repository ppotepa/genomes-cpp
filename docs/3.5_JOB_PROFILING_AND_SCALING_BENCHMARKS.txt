======================================================================
PUBLIC CONTRACTS
======================================================================
1. Metrics counters include submitted, executed, stolen, inlineExecuted, cancelled, queueWaitNs, executeNs, workerSleepNs, maxQueueDepth.

2. Per-worker counters use cache-line separation/padding to avoid false sharing; aggregate on snapshot, not atomic contention per dashboard read.

3. Profiling tags are stable small IDs/string literals assigned at submission; no dynamic string allocation in worker hot path.

4. Scaling suite records 1,2,4,8,... workers up to hardware max and emits JSON compatible with 0.4 policy.

======================================================================
DATA LAYOUT
======================================================================
Use compact value types, explicit ownership, contiguous storage in hot paths, and no hidden shared mutable state.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Add per-worker metrics with relaxed atomics or worker-owned counters where safe.

STEP 2
    Timestamp queue wait only when metrics level enabled; compile/runtime off path has minimal overhead.

STEP 3
    Implement snapshot/aggregate API.

STEP 4
    Create benchmark workloads: uniform CPU, uneven CPU, fan-out/fan-in, nested parallelFor, memory-bandwidth-limited.

STEP 5
    Calculate speedup S(P)=T1/TP and efficiency E(P)=S(P)/P in report tool/output.

STEP 6
    Record hardware_concurrency, compiler/build config, worker count and task count.

======================================================================
PSEUDOCODE
======================================================================
WORKER EXECUTE:
    t0 := now()
    job := dequeue()
    t1 := now()
    execute(job)
    t2 := now()
    metrics.queueWait += t1-job.enqueuedAt
    metrics.execute += t2-t1
    metrics.executed += 1

REPORT:
    for P in workerCounts:
        TP := median(repeatedRun(P))
        speedup := T1 / TP
        efficiency := speedup / P
