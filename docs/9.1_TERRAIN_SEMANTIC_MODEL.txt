======================================================================
PUBLIC CONTRACTS
======================================================================
1. TerrainSpec includes world/region extent, sample resolution, generator version/seed path and optional biome/material parameters. Resolution is samples per axis/cell size, never inferred from renderer mesh.

2. HeightField stores row-major float or quantized height samples plus explicit origin/cellSize/dimensions. Sampling APIs: nearest grid, bilinear height, gradient/normal using documented boundary policy.

3. TerrainArtifact may reference adjacent region border samples/ghost ring to guarantee seam-consistent normals and sampling.

4. Road/pad grading produces a new versioned terrain artifact/patch overlay; it does not mutate hidden render geometry.

======================================================================
DATA LAYOUT
======================================================================
HeightField: contiguous row-major heights, optional material/slope fields in separate arrays. Index = z*width+x. Region borders duplicate or reference one canonical edge policy explicitly.

PSEUDOCODE
======================================================================
BILINEAR:
    gx := (x-origin.x)/cellSize
    gz := (z-origin.z)/cellSize
    ix := floor(gx); iz := floor(gz)
    fx := gx-ix; fz := gz-iz
    h00,h10,h01,h11 := bounded samples
    return lerp(lerp(h00,h10,fx),lerp(h01,h11,fx),fz)

NORMAL:
    dx := (height(x+e,z)-height(x-e,z))/(2e)
    dz := (height(x,z+e)-height(x,z-e))/(2e)
    return normalize((-dx,1,-dz))

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Published height fields are immutable. Parallel generators write disjoint rows/tiles into candidate buffers before publish.

======================================================================
ERROR HANDLING
======================================================================
Invalid procedural candidates return ValidationReport/Result. Active world is changed only through generation transaction commit.

======================================================================
DETERMINISM RULES
======================================================================
Sample output for a frozen artifact is independent of renderer/GPU. Border policy deterministic across region generation order.

======================================================================
PERFORMANCE RULES
======================================================================
Height sample O(1), no raycast/no noise recompute. Contiguous fields and ghost-border layout support SIMD/cache-friendly row processing.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET terrain provides O(1) authoritative sampling and explicit grading
semantics. Reference terrain code is diagnostic evidence only.
