======================================================================
PUBLIC CONTRACTS
======================================================================
1. Memory telemetry categories: persistent semantic, ECS/runtime, artifact cache, generation scratch, render CPU, GPU buffers/textures, physics, nav, reference/debug. Unknown/untracked significant allocations are a diagnostic category.

2. Budget profiles are per hardware tier/config and distinguish steady-state target, warning high-water and hard fail/test ceiling.

3. Peak generation may exceed steady world memory but must be measured; transactional START NEW old+candidate overlap gets explicit temporary budget rather than hidden leak.

4. Caches expose retained bytes/entries/refcounts and deterministic eviction policy. Clearing/releasing last reference returns memory according to allocator/backend lifecycle.

5. VRAM estimates use actual resource descriptions/accounting where backend exposes; do not label process heap as VRAM.

======================================================================
DATA LAYOUT
======================================================================
MemoryCounter atomic/thread-local aggregated counters by category + highWater; snapshot immutable. Budget config versioned JSON/data. GPU telemetry has estimated/driver-reported distinction.

======================================================================
PSEUDOCODE
======================================================================
COUNTER:
    on ownership acquire(bytes,category):
        current[category] += bytes
        highWater[category] := max(highWater,current)
    on release:
        current[category] -= bytes
        assert current >= 0

BUDGET CHECK:
    snapshot := memoryTelemetry.snapshot()
    for category:
        if snapshot.current > hardLimit: FAIL test
        if snapshot.highWater > warning: report
    after teardown:
        require transient categories == baseline
        require persistent cache <= configured retained budget

LEAK LOOP:
    baseline := snapshot()
    repeat N:
        create world
        exercise
        dispose
    force/drain deferred destroys
    final := snapshot()
    compare plateau with allowed caches

======================================================================
