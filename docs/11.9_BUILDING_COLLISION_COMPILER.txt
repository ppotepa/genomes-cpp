======================================================================
PUBLIC CONTRACTS
======================================================================
1. Collision recipe separates coarse query proxy, static walk/block shapes and optional per-structural-element damage shapes. Jolt objects are not created here.

2. Openings remain passable: wall collision generated as segments/panels around door/window voids where relevant to agent/projectile scale.

3. Logical projectile/destruction query can use structural planes/polygons directly, not necessarily physics triangle mesh.

4. FAR/undamaged static building uses low shape count; damage activation may replace local pieces lazily.

======================================================================
DATA LAYOUT
======================================================================
Semantic plan arrays remain renderer/physics/nav independent. Compiler products are versioned artifacts keyed by BuildingPlan fingerprint.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Compile exterior/interior wall panel boxes/convexes split around openings using semantic wall intervals.

STEP 2
    Compile slab/roof/foundation static shapes with simplification threshold.

STEP 3
    Build coarse AABB/OBB proxies for world broadphase and BuildingSpatialIndex replacement.

STEP 4
    Store StructuralElementId on every damage-relevant collision recipe part.

STEP 5
    Define localized invalidation mapping element/bounds -> collision chunk.

STEP 6
    Compare logical segment hits against SOURCE building collision proxy fixtures.

======================================================================
PSEUDOCODE
======================================================================
WALL COLLISION:
    intervals := wall span minus door/window horizontal intervals per vertical bands
    for solid rectangle band:
        emit Box/Convex(shape, elementId)

DAMAGE:
    on element changed:
        dirtyChunks := collisionMap[elementId]
        rebuild only dirty chunks
        swap recipes/backend bodies at safe commit

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Building plan is immutable. Compilers can run independently/parallel from the same plan revision and publish separate representation artifacts.

======================================================================
ERROR HANDLING
======================================================================
Compiler failure never mutates BuildingPlan. Return typed errors/ValidationReport and keep prior valid representation if rebuilding.

======================================================================
DETERMINISM RULES
======================================================================
Compiler output identity derives from plan fingerprint + compiler version/options. Job completion order never changes content.

======================================================================
PERFORMANCE RULES
======================================================================
Batch/merge geometry and queries; cache compiler products by plan hash; avoid one object per architectural micro-feature.

======================================================================
MIGRATION / COMPATIBILITY
