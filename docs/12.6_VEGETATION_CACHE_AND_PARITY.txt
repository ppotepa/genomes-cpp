4. Scatter parity checks distributions/invariants rather than exact Three.js scene objects.

======================================================================
DATA LAYOUT
======================================================================
Cache keys are explicit tuples:
    explicit vegetation generator version (environmentGeneratorVersion /
    PlantGenome version domain), never the building generator version
    species/prototype definition version
    genome/seed hash
    geometry-affecting age/season/detail parameters

Cache entries hold immutable PlantPrototypeArtifact plus byte size/refcount and
derived representation handles owned by the corresponding renderer cache.

Parity fixtures store:
    SOURCE commit
    SOURCE version.json environmentGeneratorVersion
    PlantGenome.version
    and, separately, the observed legacy accidental R.Config.GENERATOR_VERSION
    value where needed to explain historical cache keys
    species/seed/state/detail
    semantic genome
    branch/skeleton metrics
    bounds/counts/buffer hashes where exact
    parity policy/tolerances

World instance identity and prototype-cache identity are separate.
