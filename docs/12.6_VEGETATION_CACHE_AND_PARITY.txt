PUBLIC CONTRACTS
======================================================================
1. Fixtures include all TARGET species/rock families across selected
age/season/LOD combinations and layout seeds.

2. Validation checks TARGET genome identity, structural/visual quality metrics
and exact sync-vs-parallel semantic equality.

3. Cache tests cover duplicate-key hit, refcount/lifetime, retained bytes, eviction and cancellation cleanup.

4. Scatter validation checks distributions/reservations rather than scene objects.

======================================================================
DATA LAYOUT
======================================================================
Cache keys are explicit tuples:
    explicit TARGET vegetation/PlantGenome schema identity
    species/prototype definition version
    genome/seed hash
    geometry-affecting age/season/detail parameters

Cache entries hold immutable PlantPrototypeArtifact plus byte size/refcount and
derived representation handles owned by the corresponding renderer cache.

TARGET fixtures store:
    TARGET commit and schema identities
    species/seed/state/detail
    semantic genome
    branch/skeleton metrics
    bounds/counts/buffer hashes where exact
    validation policy/tolerances

World instance identity and prototype-cache identity are separate.
