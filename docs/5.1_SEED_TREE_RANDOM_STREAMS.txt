======================================================================
PUBLIC CONTRACTS
======================================================================
1. Seed is uint64 semantic root. SeedPath derives child seeds from parent seed + stable UTF-8 label + stable uint64 index using a frozen derivation version.

2. RandomStream algorithm AND seed-derivation algorithm are explicitly
versioned. SOURCE does not use one universal derivation scheme.

Required compatibility adapters:
    LegacyMulberry32
    LegacyBuildingDeriveSeed32
    LegacyCitySeedTree32
    LegacyPlantLabelStream32

See:
    ALG-RNG-MULBERRY32-LEGACY-001
    ALG-RNG-BUILDING-DERIVE32-001
    ALG-RNG-CITY-SEEDTREE32-001
    ALG-RNG-PLANT-LABEL32-001

3. Default canonical native v1 is PCG32 with 64-bit state/stream selector,
seeded from the canonical native SeedPath/StableHash tuple.

However, a migration chapter requesting EXACT SOURCE parity MUST use the
correct SOURCE compatibility derivation adapter for its fixture/generator
version. It may switch to native SeedTree only through an explicit generator
version change and parity report.

4. RandomStream provides nextU32, uniform01 [0,1), uniformRange, bounded integer using rejection to avoid modulo bias.

PSEUDOCODE
======================================================================
CHILD:
    bytes := encode(
        seedDerivationVersion,
        parentSeed,
        length(label), labelUTF8,
        stableIndex
    )
    child := stableHashBytes(bytes)
    if child == 0: child := reservedNonZeroRemap
    return Seed(child)

PARALLEL:
    parallel_for item:
        rng := RandomStream(seed.child("building", item.id))
        result[item.id] := generate(rng)
    // no shared RNG
