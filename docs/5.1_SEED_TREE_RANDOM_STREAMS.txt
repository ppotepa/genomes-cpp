======================================================================
PUBLIC CONTRACTS
======================================================================
1. Seed is uint64 semantic root. SeedPath derives child seeds from parent seed + stable UTF-8 label + stable uint64 index using a frozen derivation version.

2. RandomStream algorithm and seed derivation are explicit TARGET schemas.
Production uses only canonical SeedPath + PCG streams. Reference-export RNGs,
if needed by tooling, are outside engine/proc and cannot be selected at runtime.

3. Canonical native v1 is PCG32 with 64-bit state/stream selector,
seeded from the canonical native SeedPath/StableHash tuple.

TARGET generators never select algorithms from fixture provenance or
compatibility configuration.

4. RandomStream provides nextU32, uniform01 [0,1), uniformRange, bounded integer using rejection to avoid modulo bias.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Freeze SeedDerivationVersion=1 and encode tuple fields with type/length delimiters to avoid concatenation ambiguity.

STEP 2
    Implement child(label,index) and childStableId(label,id.value).

STEP 3
    Implement PCG32 canonical stream with published reference constants and golden vectors; record primary PCG source in 0.5 if missing.

STEP 4
    Implement unbiased bounded uint generation via rejection threshold.

STEP 5
    Add schedule-independence test: derive 10k child streams in shuffled parallel order and compare by stable index.

STEP 6
    Add semantic-isolation tests proving that inserting an unrelated domain,
    entity or gene does not perturb existing paths.

PSEUDOCODE
======================================================================
CHILD:
    bytes := encode(
        seedDerivationVersion,
        parentSeed,
        length(label), labelUTF8,
        stableIndex
    )
    child := stableHashBytes(bytes)
    if child == 0: child := reservedNonZeroRemap
    return Seed(child)

PARALLEL:
    parallel_for item:
        rng := RandomStream(seed.child("building", item.id))
        result[item.id] := generate(rng)
    // no shared RNG
