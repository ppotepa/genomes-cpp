PUBLIC CONTRACTS
======================================================================
1. Validation checks graph components among required network, duplicate/zero
edges, node degree, unregistered level-0 crossings, invalid centerline
self/intersections, water crossings, bridge annotations, out-of-bound nodes,
class validity and exact edge-node endpoint agreement.

2. Crossing validation uses RoadSpatialIndex broadphase and an adaptive
piecewise-linear representation of each RoadCenterline for robust-predicate
narrow phase. Shared topological endpoints are not errors.

The adaptive representation is for query/validation only; it does not become
the authoritative curve.

3. Junction geometry validation requires:
    edge.centerline.start == node[a].position
    edge.centerline.end   == node[b].position

and for split children the shared split endpoint is exactly the same canonical
node coordinate.

4. Connectivity policy differentiates required major skeleton from optional dead-end local roads.

5. Validator reports metrics: nodes/edges, components, road length by class, degree distribution, dead-end %, bridge count, invalid crossings.

======================================================================
DATA LAYOUT
======================================================================
Graphs use contiguous node/edge arrays with stable IDs and adjacency ranges; fields are grid/raster artifacts; polygons use engine geometry types.

PSEUDOCODE
======================================================================
CROSSINGS:
    for edge in stable ID order:
        candidates := index.query(edge.bounds)
        for otherId > edgeId:
            if share endpoint: continue
            hit := robustIntersect(edge,other)
            if proper hit and same level:
                issue UnregisteredCrossing

CONNECTIVITY:
    visit from required gateway/center root
    for required node:
        if !visited: issue DisconnectedRequiredNetwork
