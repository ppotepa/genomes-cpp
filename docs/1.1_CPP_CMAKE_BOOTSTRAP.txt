CHAPTER 1.1 - C++ / CMAKE BOOTSTRAP
STATUS: READY
VERSION: 0.1

======================================================================
GOAL
======================================================================

Create the first native C++ build skeleton INSIDE the existing Genomes
repository without removing, moving, modifying or disabling the current
browser runtime.

After this chapter:

    - existing JS/browser Genomes still works,
    - CMake configures a native project,
    - genomes_foundation static library builds,
    - genomes_headless command-line app builds,
    - one native CTest smoke test passes,
    - native and legacy implementations coexist,
    - all later native chapters have stable target/directory conventions.

This chapter intentionally introduces NO external native dependencies.

STEP 3 - ROOT CMakeLists.txt

Required structure:

    project(
        Genomes
        VERSION 0.1.0
        LANGUAGES CXX
    )

        "\${CMAKE_CURRENT_SOURCE_DIR}/cmake"

    add_subdirectory(engine)
    add_subdirectory(apps)

        add_subdirectory(tests/native)
    endif()

    endif()

STEP 5 - WARNING FUNCTION

Create:

    function(genomes_set_project_warnings target)

MSVC-compatible concept:

    /W4
    /permissive-

    if warnings-as-errors:
        /WX

GCC/Clang concept:

    -Wall
    -Wextra
    -Wpedantic

    if warnings-as-errors:
        -Werror

Apply ONLY to Genomes-owned targets.

Do not globally poison future vendor targets.

            "0.1"
        )

WARNING POLICY:

    function genomes_set_project_warnings(target):
        if compiler is MSVC-compatible:
            target += /W4 /permissive-
            if warningsAsErrors:
                target += /WX

        else if compiler is GCC-or-Clang:
            target += -Wall -Wextra -Wpedantic
            if warningsAsErrors:
                target += -Werror
