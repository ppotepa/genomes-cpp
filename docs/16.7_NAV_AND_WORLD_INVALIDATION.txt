======================================================================
PUBLIC CONTRACTS
======================================================================
1. Every committed geometry/support/rubble change emits DirtyBounds{worldAabb, reasonMask, sourceRevision, region IDs}.

2. Consumers are independent: NavigationDirty, StaticQueryDirty, RenderRepresentationDirty, PhysicsDirty. One failed consumer does not roll back already authoritative semantic damage unless its contract requires transaction.

3. Dirty bounds coalesce spatially/temporally with deterministic rules and maximum expansion limits; never mark entire world for a local hole by default.

4. Queries against semantic destruction state are correct immediately. Compiled nav/render/static proxies expose revision and may be conservatively stale until rebuild.

5. Region unload/load persists dirty semantic revision so derived data is rebuilt or loaded at matching artifact revision.

======================================================================
DATA LAYOUT
======================================================================
DirtyBounds compact value type: AABB3, reason bitmask, source Object/Region IDs, semanticRevision. Per-consumer dirty queues are region-bucketed.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define reason flags: StructuralGeometry, RubbleSurface, Traversability, Cover, StaticCollision, Presentation.

STEP 2
    At destruction commit, compute conservative world AABB from affected semantic parts/tiles and emit one or more DirtyBounds.

STEP 3
    Implement deterministic coalescing within region/grid bucket using union if overlap/near threshold and revision compatibility.

STEP 4
    Feed NavigationWorld dirty tile API from Traversability/Structural changes.

STEP 5
    Feed world static query/BVH incremental rebuild or overlay path.

STEP 6
    Feed presentation extraction dirty revisions; do not force full scene rebuild.

STEP 7
    Test destruction near region boundary marks all overlapping regions/tiles.

======================================================================
PSEUDOCODE
======================================================================
EMIT:
    dirty := boundsOf(changedSemanticData)
    reasons := deriveReasonMask(change)
    for region in world.regionsOverlapping(dirty):
        queues[region].push({dirty,reasons,revision})

COALESCE:
    stable_sort queue by minCell, revision, sourceId
    for event in queue:
        if compatible(last,event) and distance(last,event) <= threshold:
            last.bounds := union(last.bounds,event.bounds)
            last.reasons |= event.reasons
        else:
            output.push(event)

CONSUME NAV:
    for dirty in navQueue:
        nav.markTilesDirty(dirty.bounds, dirty.revision)

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Producers write thread-local dirty events. Commit merges/sorts. Consumers may rebuild in parallel after semantic commit and publish by revision.

======================================================================
ERROR HANDLING
======================================================================
Consumer rebuild failure leaves dirty item pending and keeps previous conservative representation; report telemetry. Invalid/nonfinite bounds is programmer error.

======================================================================
DETERMINISM RULES
======================================================================
Coalescing uses stable sort and fixed thresholds, independent of worker completion.

======================================================================
PERFORMANCE RULES
======================================================================
Bound dirty region expansion; benchmark 10k small impacts vs tile/BVH rebuild counts. Coalescing must reduce duplicate rebuilds.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
SOURCE has ad-hoc world bridges; TARGET replaces with generic revisioned invalidation, preserving behavior not coupling.
