======================================================================
PUBLIC CONTRACTS
======================================================================
1. BuildingNavRecipe contains walkable floor polygons, obstacle wall polygons, door portals, stair/off-mesh vertical connections, floor levels and exterior entrances.

2. Semantic room/circulation graph is preserved separately for tactical high-level movement even when local Detour navmesh changes.

3. Door state can toggle portal/obstacle dynamically without regenerating BuildingPlan.

4. Nav dirty mapping ties structural elements/openings to affected local tiles/bounds.

======================================================================
DATA LAYOUT
======================================================================
Semantic plan arrays remain renderer/physics/nav independent. Compiler products are versioned artifacts keyed by BuildingPlan fingerprint.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Extract walkable polygons from spaces/corridors minus wall thickness/obstacles.

STEP 2
    Emit doorway portals with width/height/connected SpaceIds and exterior world endpoint.

STEP 3
    Emit stair flight/landing connection recipe; choose navmesh ramp/poly/off-mesh representation later in Recast backend based slope/profile.

STEP 4
    Generate high-level SpaceGraph nodes/edges for room/corridor/vertical/exterior topology.

STEP 5
    Validate every nonsealed space reachable from at least one permitted entrance according program.

STEP 6
    Map destruction of wall/door/slab to NavDirtyBounds.

======================================================================
PSEUDOCODE
======================================================================
SPACE GRAPH:
    node per SpaceId
    for door opening:
        add edge(spaceA,spaceB,portalId)
    for stair:
        add vertical edge(landingFloorA,landingFloorB)
    for exterior entrance:
        add world portal edge

NAV RECIPE:
    for floor:
        emit walkable polygons
        emit wall obstacles
        emit portals/connections

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Building plan is immutable. Compilers can run independently/parallel from the same plan revision and publish separate representation artifacts.

======================================================================
ERROR HANDLING
======================================================================
Compiler failure never mutates BuildingPlan. Return typed errors/ValidationReport and keep prior valid representation if rebuilding.

======================================================================
DETERMINISM RULES
======================================================================
Compiler output identity derives from plan fingerprint + compiler version/options. Job completion order never changes content.

======================================================================
PERFORMANCE RULES
======================================================================
Batch/merge geometry and queries; cache compiler products by plan hash; avoid one object per architectural micro-feature.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET BuildingPlan and compiler validators define behavior; no renderer or
physics reference implementation selects a production path.
