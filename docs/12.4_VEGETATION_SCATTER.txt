PUBLIC CONTRACTS
======================================================================
1. Scatter input fields: TerrainArtifact, zone/biome/reserved masks, hydrology, seed, density, prototype catalog. Output EnvironmentLayout immutable instance records.

2. Instance record: stable InstanceId, prototype ID, world/local transform, scale/width scale, footprint, optional burial/formation metadata. Passive instance is not ECS.

3. Candidate spacing uses spatial grid or Bridson-like Poisson strategy; no O(N²) scan of all prior instances at target scale.

4. Orchards/crops/fields may use structured row/grid patterns with deterministic jitter distinct from natural scatter.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define separate scatter layers Tree/Shrub/Orchard/Crop/Rock with priority/reservation interactions.

STEP 2
    Generate cluster centers/patches using seeded semantic IDs and validate against terrain/zone masks.

STEP 3
    Within patches sample candidates using Poisson/grid hybrid and DynamicGrid2D footprints.

STEP 4
    Sample terrain height/normal once accepted; reject slope thresholds by layer.

STEP 5
    Assign prototype/scale/rotation from independent child streams.

STEP 6
    Produce stable instance pages sorted/grouped later by prototype, not generation completion.

======================================================================
PSEUDOCODE
======================================================================
FOR layer:
    centers := generateClusterCenters(seed.child(layer))
    spatial := grid(cellSize)
    for center stable:
        attempts := bounded
        candidates := poisson/row pattern
        for c:
            if reserved/water/slope/zone invalid: continue
            if spatial.neighborConflict(c, footprint): continue
            id := derive(layer,centerId,acceptedOrdinal)
            add instance
            spatial.insert(id,bounds)

THREADING / OWNERSHIP RULES
======================================================================
Different spatially independent tiles/layers may generate in jobs; conflicts across tile borders require halo/canonical ownership and deterministic merge/revalidation.

======================================================================
ERROR HANDLING
======================================================================

======================================================================
DETERMINISM RULES
======================================================================
Stable tile/cluster IDs and seed paths. Border conflict winner = lower stable InstanceId/priority, not job completion.

======================================================================
PERFORMANCE RULES
======================================================================
Spatial neighbor checks bounded by local cells; target supports millions of passive instances via pages.
