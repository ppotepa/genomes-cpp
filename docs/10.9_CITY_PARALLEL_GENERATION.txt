======================================================================
PUBLIC CONTRACTS
======================================================================
1. City generation is a GenerationGraph: terrain/hydrology inputs -> core -> transport/regions -> local road proposals -> zoning -> blocks -> parcels -> building requests.

2. Independent leaf regions may evaluate local road candidates in parallel against stable snapshots; commits that can conflict are stable-ordered/revalidated.

3. Zoning cells, block post-processing and parcel generation per independent block parallelize naturally with output arrays keyed by stable IDs.

4. Serial reference mode uses same code paths with workerCount=1.

======================================================================
DATA LAYOUT
======================================================================
Graphs use contiguous node/edge arrays with stable IDs and adjacency ranges; fields are grid/raster artifacts; polygons use engine geometry types.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Express stage dependencies in GenerationGraph rather than nested async calls.

STEP 2
    Batch RegionNode leaf jobs; local results return proposals/artifacts, not direct global mutation.

STEP 3
    Stable merge road proposals; after final graph freeze parallelize zoning and block parcel work.

STEP 4
    Use job-local ScratchContext for polygon/route work.

STEP 5
    Benchmark city sizes .25/4/25/100 km² where practical and worker counts 1..N.

STEP 6
    Record stage critical path, job utilization, memory high-water.

======================================================================
PSEUDOCODE
======================================================================
GRAPH:
    core := cityCore()
    skeleton := majorRoads(core)
    regions := subdivide(core,skeleton)
    localProposals := parallelMap(regions.leaves, growLocalSnapshot)
    roads := stableCommit(localProposals)
    zoneField := parallelRaster(roads)
    blocks := extractFaces(roads)
    parcelChunks := parallelMap(blocks, generateParcels)
    parcels := stableMerge(parcelChunks)
    buildingRequests := parallelMap(parcels, makeRequest)

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
No shared RoadGraph mutation from workers. Block/parcel jobs own disjoint semantic IDs/output slots.

======================================================================
ERROR HANDLING
======================================================================
Invalid candidates are rejected through typed result/ValidationReport; bounded fallback strategies are explicit and traced.

======================================================================
DETERMINISM RULES
======================================================================
Worker count/scheduling produces identical canonical artifact hashes in exact-deterministic stages.

======================================================================
PERFORMANCE RULES
======================================================================
Benchmark stage-by-stage; avoid overparallelizing tiny hamlets. Auto policy can execute small city serially.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Improves SOURCE single-thread prototype execution without changing semantic requirements.
