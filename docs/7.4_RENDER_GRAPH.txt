======================================================================
PUBLIC CONTRACTS
======================================================================
1. Pass declares reads/writes/attachments/queue preference before execution. Hidden resource access is forbidden.

2. Graph compiler detects write-write/read-write dependencies, topologically sorts, culls unused passes, computes transient resource lifetime and aliases only compatible non-overlapping resources.

3. Backend executor translates logical states/transitions to Diligent resource barriers and queue synchronization.

4. Imported persistent resources (swapchain/GPUScene) are never transient-aliased.

======================================================================
DATA LAYOUT
======================================================================
Public renderer-facing handles are compact generational values. Backend objects are private implementation data.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define GraphTexture/GraphBuffer logical handles valid only within graph build.

STEP 2
    Implement pass builder resource usage declaration and execute callback with resolved physical handles.

STEP 3
    Compile dependency graph; reject cycles and conflicting undeclared access.

STEP 4
    Implement lifetime firstUse/lastUse and simple transient pool reuse before true memory aliasing optimization.

STEP 5
    Emit state transitions/barriers per logical usage and verify debug validation.

STEP 6
    Add graph visualization dump DOT/JSON for proc/debug tooling.

======================================================================
PSEUDOCODE
======================================================================
COMPILE:
    for pass:
        for resource access:
            connect dependency from lastWriter/readers as needed
    topo := topologicalSort()
    cull passes not contributing to exported outputs unless sideEffect
    for resource:
        lifetime := [firstUse,lastUse]
        physical := transientPool.acquireCompatible(lifetime,desc)
    derive barriers between consecutive usages

EXECUTE:
    for pass in topo:
        apply barriers
        pass.callback(resolvedResources)


======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Render backend owns GPU objects. Simulation never touches Diligent objects. Render extraction consumes immutable snapshots and stages uploads.

======================================================================
ERROR HANDLING
======================================================================
Device/shader/resource failures return typed errors with diagnostics; no silent fallback that changes correctness or feature policy.

======================================================================
DETERMINISM RULES
======================================================================
Presentation may be frame-order nondeterministic, but stable semantic IDs map to persistent GPU records; no render result feeds authoritative gameplay unless explicitly specified.

======================================================================
PERFORMANCE RULES
======================================================================
Minimize CPU submission, resource churn, state changes and readbacks. All GPU features are capability/benchmark driven.
