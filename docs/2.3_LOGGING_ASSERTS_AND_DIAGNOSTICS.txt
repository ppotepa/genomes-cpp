PUBLIC CONTRACTS
======================================================================
1. LogLevel = Trace, Debug, Info, Warn, Error, Fatal. A LogRecord carries monotonic timestamp, thread id/hash, category, level, message and optional fixed-size fields. Logging API must allow disabled levels to return before formatting.

2. ILoggerSink is an interface owned by the diagnostics service. Default sinks: stderr console and bounded in-memory ring for tests. The service is injected; no mandatory global singleton.

3. GENOMES_ASSERT(expr) is compiled for programmer invariants in debug/development; GENOMES_VERIFY(expr) evaluates in all builds; GENOMES_UNREACHABLE() has a diagnostic path before optimizer hint.

4. DiagnosticScope attaches subsystem/job/region identifiers to records through explicit scope objects; thread-local scope stack is allowed only as diagnostics metadata, never gameplay state.

======================================================================
DATA LAYOUT
======================================================================
Use compact value types, explicit ownership, contiguous storage in hot paths, and no hidden shared mutable state.

PSEUDOCODE
======================================================================
LOG FAST PATH:
    function log(level, category, builder):
        if level < compileFloor: return
        router := diagnostics.router
        if !router.accepts(level, category): return
        record := builder.buildInto(threadLocalScratch)
        router.emit(record)

ASSERT:
    macro GENOMES_ASSERT(expr):
        if !(expr):
            reportAssertFailure(#expr, source_location)
            terminateOrDebugBreak()

DIAGNOSTIC SCOPE:
    constructor(scope):
        previous := tlsScopeTop
        tlsScopeTop := this
    destructor:
        tlsScopeTop := previous
