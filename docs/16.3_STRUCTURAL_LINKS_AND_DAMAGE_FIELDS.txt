======================================================================
PUBLIC CONTRACTS
======================================================================
1. DamageField is local to StructuralElement/Solid and stores bounded cells or sparse tiles with crush, crack, weakness, rearDamage plus explicit Hole records containing channel geometry and removedVolume. Aggregate damage is diagnostic only.

2. Damage application is spatial/local: ImpactResult deposits energy/work into nearby cells and may cut a through-channel only after penetration geometry confirms traversal. A local hit never automatically destroys an entire wall.

3. StructuralGraph is directed support graph with element category, anchors, edge support type/cost/span and current integrity. Foundation/world anchors are explicit; roof/slab/side support rules come from building structural model.

4. Detach eligibility requires structural/support failure or explicit terminal destruction rule. Geometry subdivision limit does not make remaining wall immortal: at budget/depth limit, state transitions to weakened/terminal/detach/remove according documented policy.

5. DamageField geometry and structural graph revisions are semantic sources for render collision/nav compilers; all representations consume same committed damage revision.

======================================================================
DATA LAYOUT
======================================================================
Damage cells use sparse/local grid keyed in material frame with fixed maximum cells per element/chunk; Hole vector bounded by geometry budget and can merge overlapping channels. Structural graph uses compact adjacency arrays plus mutable integrity/status arrays keyed StructuralElementId.

PSEUDOCODE
======================================================================
APPLY DAMAGE:
    local := element.frame.toLocal(impact.point)
    cells := damageField.cellsWithin(local, radius)
    distribute work/impulse metrics deterministically
    if impact penetrated:
        hole := channel(entry,exit,radii,removedVolume)
        merge/add hole within budget
    update integrity metrics

SUPPORT CASCADE:
    dirty := elements whose integrity/support changed
    repeat waves bounded by element count:
        detachList := []
        for element in dirty sorted ID:
            if element is anchor: continue
            if !hasValidSupportPath(element, graph, span/cost limits):
                detachList.push(element)
        if empty: break
        mark all detachList Detached
        dirty := neighbors affected
    emit one representation invalidation batch

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Impact jobs emit DamageCommands. One destruction commit owns DamageField/StructuralGraph mutation per target/building. Different buildings can commit in parallel if world event ordering does not conflict.

======================================================================
ERROR HANDLING
======================================================================
Damage budget overflow uses explicit merge/coarsen/terminal policy and reports metrics; it must not restore original geometry or silently discard removed material.

======================================================================
DETERMINISM RULES
======================================================================
Damage cell addressing/material-local field and cascade waves stable by element IDs. Simultaneous hits are committed by semantic sequence key.

======================================================================
PERFORMANCE RULES
======================================================================
Local sparse cells, spatially limited support rechecks, batched representation invalidation. No full building mesh/collider rebuild per impact.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Preserve latest SOURCE behavior over older contradictory docs. The persistent rubble/conservation path in 16.4-16.5 supersedes legacy "delete debris when pool full".
