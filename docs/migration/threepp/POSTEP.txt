WHAT IS NOW TRUE
----------------
1. dev-debug/dev-release and rundev/run-release are THREEPP_GL-first and no longer require FXC.
2. Diligent is optional legacy fallback; it is not the ordinary run path.
3. UnitLab uses the same immutable infantry model artifact and skinned prototype contract as world units.
4. Threepp consumes neutral MaterialDescriptor + MeshMaterialGroup data; it does not hard-code
   infantry skin/hair/cloth region numbers.
5. Skeleton identity, hierarchy, inverse binds and local poses are explicit neutral data.
6. Immutable geometry upload is cache/revision driven; pose revisions update only live bone/morph state.
7. UI texture payloads are revision cached, UI buffers grow geometrically and telemetry is exposed.
8. RmlUi consumes input per event; unrelated scene events in the same frame are retained.
9. UnitLab interactive orbit/pan/zoom is owned by threepp OrbitControls, not duplicate scene math.
10. UnitLab exposes:
    - six camera presets
    - locomotion presets
    - pause/resume
    - seven expressions + intensity
    - detail / seed / variation / loadout
    - all GenomeGene entries through generic select +/-/clear controls
    - all equipment slots through generic slot/item/empty/loadout override cycling
    - surface, skeleton, bounds, normals, wireframe and bone-weight diagnostics
11. Character lighting uses sRGB output + ACES, modern light units, camera-relative key shadows;
    the previous key-light sign that placed +Y lighting below the target is corrected.
12. Skinned world units have conservative shared culling bounds and distance-driven animation cadence.
13. Deterministic captures can select camera, locomotion and expression from CLI.
14. Startup prints configure-time git SHA/state/backend and runtime GL identity.
