======================================================================
PUBLIC CONTRACTS
======================================================================
1. ProjectileState stores ProjectileId/ShotId/optional ParentProjectileId, ammunition strategy/profile IDs, mass, effective diameter, position, world velocity, orientation quaternion, angular velocity, local inertia parameters, deformation/integrity/stability, age, travel distance, current contact state and lifecycle state Flight/Contact/Fragment/Detonated/Stopped/GroundContact/TrackingLimit.

2. EnergyLedger fields are explicit signed categories: initial translational/rotational, flightWork, rotationWork, materialWork, contactLoss, targetWork, fragmentEnergy, explosiveEnergy, blastEnergy, unrepresentedEnergy and residual balanceError. Ledger is diagnostic/accounting; solver does not force residual to zero.

3. AmmunitionProfile identifies caliber/strategy/variant/construction/calibration plus base mass/diameter/muzzle velocity, aerodynamic profile, ricochet/material override profile and optional HE/fragmentation/fuze data. Strategy code owns algorithms; profile owns versioned parameters.

4. Projectile kinetic energy always derives from current mass and full velocity E=1/2*m*dot(v,v). Unit direction is separately derived. Rotational energy derives from inertia/orientation state according documented shape approximation.

5. Mass/diameter/deformation changes trigger inertia recomputation and angular-velocity rescale where strategy requires rotational-energy continuity, matching SOURCE contract.

PSEUDOCODE
======================================================================
ENERGY:
    translational(state):
        return 0.5 * state.mass * dot(state.velocity,state.velocity)

    totalTracked(state):
        return translational(state) + rotational(state)

    balance:
        expected := initialEnergy
                  + flightWork
                  + rotationWork
                  + targetWork
                  + explosiveEnergy
                  - materialWork
                  - contactLoss
                  - fragmentEnergy
                  - blastEnergy
                  - unrepresentedEnergy
        balanceError := currentTrackedEnergy - expected

DIAMETER CHANGE:
    oldRot := rotationalEnergy(state)
    state.effectiveDiameter := newDiameter
    state.inertia := recomputeInertia(state)
    if preserveRotEnergy:
        state.angularVelocity *= sqrt(oldRot / max(newRotAtOldOmega,eps))

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Projectile profiles/strategies immutable. Per-projectile state owned by ballistics batch/chunk during a substep. Impact/destruction commands emitted, not direct target mutation.

======================================================================
ERROR HANDLING
======================================================================
Invalid mass/diameter/nonfinite profile fails catalog validation. Energy ledger nonfinite or residual beyond diagnostic threshold reports error but does not silently rewrite state.

======================================================================
DETERMINISM RULES
======================================================================
Profile/version + seed + fixed-step state define results. Fragment child IDs/seeds derive from parent Shot/Projectile IDs and ordinal, never allocation/completion order.

======================================================================
PERFORMANCE RULES
======================================================================
