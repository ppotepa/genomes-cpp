======================================================================
PUBLIC CONTRACTS
======================================================================
1. ImpactInput includes projectile mass/diameter/world velocity/orientation/angular velocity, contact point/normal, target linear/angular velocity, ordered material intervals and deterministic strategy/profile IDs.

2. Relative contact velocity is v_projectile - (v_target_linear + omega_target × contactLever). Solver returns full outgoing world velocity, angular velocity, projectile impulse, target impulse and torque.

3. Material work for interval i is W_i = F_i * actualPath_i where F_i = pressure_i * projectileCrossSection. Cross-section multiplication occurs once.

4. Energy ledger never forces residual balance to zero; balanceError is independently computed diagnostic residual.

5. Solver is bounded: maximum interfaces/iterations are explicit constants/config; exhausted budget returns typed state/fallback, never infinite loop.

======================================================================
DATA LAYOUT
======================================================================
ImpactInput/ImpactResult are value structs using Vec3/Quat and spans into immutable intervals. Scratch interval traversal uses JobScratchArena. No per-impact polymorphic heap allocation.

PSEUDOCODE
======================================================================
RELATIVE VELOCITY:
    targetAtContact := targetLinear + cross(targetAngular, contactPoint - targetCOM)
    relative := projectileVelocity - targetAtContact

TRAVERSE:
    E := 0.5 * mass * dot(relative, relative)
    for interval in orderedIntervals:
        if interval.material is VOID:
            advance distance/time only
            continue
        area := PI * diameter*diameter / 4
        force := materialPressure(interval, state) * area
        work := force * interval.actualDistance
        consumed := min(E, work)
        E -= consumed
        ledger.materialWork += consumed
        if E <= stopThreshold:
            return STOPPED with impulses/ledger
    return PENETRATED with residual velocity derived from E

BALANCE:
    balanceError :=
        initialTrans + initialRot
        + flightWork + rotationWork + targetWork + explosiveEnergy
        - finalTrans - finalRot
        - materialWork - contactLoss - fragmentEnergy
        - unrepresentedEnergy - blastEnergy

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
ImpactSolver is stateless/pure over inputs plus immutable catalogs. Batch impacts freely across workers. Physics application occurs after deterministic event/command commit.

======================================================================
ERROR HANDLING
======================================================================
Invalid finite state, nonpositive mass/diameter, malformed intervals -> typed InvalidArgument. Strategy not found -> NotFound. Iteration budget -> SolverBudgetExceeded with diagnostic state.

======================================================================
DETERMINISM RULES
======================================================================
No wall time, no shared RNG. Any stochastic material variation is sampled before/through explicit SeedPath. Ordered intervals and tie-breaks are stable.

======================================================================
PERFORMANCE RULES
======================================================================
Target no allocation in solve(); reuse scratch. Benchmark scalar and later SIMD/batched paths separately. Do not vectorize at cost of changing branch semantics without parity.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Keep legacy calibration data as versioned profiles. Native numerical parity tolerances are explicit per fixture; do not retune coefficients just to hide port bugs.
