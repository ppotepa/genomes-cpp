======================================================================
PUBLIC CONTRACTS
======================================================================
1. RockGenome stable traits include family/variant, base dimensions, angularity, fracture/noise profile, material class and optional weathering; placement transform/burial is instance data, not prototype genome.

2. RockPrototypeArtifact has LOD geometry recipes, bounds, collision proxy recipe and footprint radius.

3. Noise/deformation is deterministic from semantic vertex/sample identity and does not depend on tessellation iteration order where possible.

======================================================================
PSEUDOCODE
======================================================================
GEN:
    base := choose canonical primitive(genome.family)
    vertices := tessellate(base, lodBase)
    for stable vertex semantic coordinate:
        displacement := noise(genome.seed, direction/position)
        vertex *= radius*(1+displacement)
    compute bounds
    derive LOD simplifications
