======================================================================
PUBLIC CONTRACTS
======================================================================

PARITY-CLASS-EXACT
    Exact serialized/logical equality is expected for selected deterministic
    fixtures.

PARITY-CLASS-NUMERIC
    Numeric results match within explicitly documented tolerances.

PARITY-CLASS-STRUCTURAL
    Same semantic graph/topology/schema relationships, even if internal object
    layout differs.

PARITY-CLASS-INVARIANT
    Required validity properties and constraints match; exact generated shape
    may intentionally differ.

PARITY-CLASS-BEHAVIORAL
    User/game-observable state transition behavior matches acceptance cases.

PARITY-CLASS-VISUAL
    Selected image/debug fixtures are reviewed by automated metrics and/or
    manual acceptance defined by migration chapter.

PARITY-CLASS-PERFORMANCE
    New implementation must meet or improve explicit benchmark ceilings.

A subsystem can require multiple classes.

RETIREMENT STATES:

    KEEP
        legacy stays indefinitely as active/reference tool.

    REFERENCE_ONLY
        legacy no longer production path but retained for parity/research.

    RETIRE_AFTER_PARITY
        legacy production path may be removed after named parity chapter.

    NEVER_DELETE_FIXTURE
        test/research artifact retained as regression evidence.

PSEUDOCODE
======================================================================

MIGRATION GATE:

    function mayRetireLegacy(subsystem):
        row := MigrationInventory[subsystem]

        require row.nativeOwnerImplemented
        require row.requiredParityTestsExist
        require all(row.requiredParityTests.pass)
        require row.dependentsUseNativePath
        require row.referenceArtifactsPreserved

        if row.retirementRule == KEEP:
            return false

        if row.retirementRule == REFERENCE_ONLY:
            markLegacyNonShipping()
            keepReferenceFiles()
            return true

        if row.retirementRule == RETIRE_AFTER_PARITY:
            return true

        return false
