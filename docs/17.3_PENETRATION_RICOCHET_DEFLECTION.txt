======================================================================
PUBLIC CONTRACTS
======================================================================
1. ContactResolver receives ordered MaterialIntervals from semantic hit plus target motion and returns ContactOutcome{Penetrated,Stopped,Ricocheted,Glanced,Deflected,...}, ImpactResult and optional damage commands.

2. Penetration with residual energy continues same ProjectileId/TraceId; do not spawn a new projectile merely for exiting a layer.

3. Ricochet decision belongs to AmmunitionStrategy/material profile and uses explicit incidence convention. Narrow ammo/material overrides are data, not shared material mutation.

4. Outgoing direction/velocity comes from resolver result and updates orientation/stability consistently through ProjectileState transition.

5. Damage budget and target impulse are emitted once per physical contact/interface group; technical subdivisions sharing physicalSolidId do not duplicate contact loss.

======================================================================
DATA LAYOUT
======================================================================
ContactCandidate immutable; ContactOutcome value object; damage/impulse commands buffered. Keep material intervals as span/small vector from query scratch.

STEP 2

STEP 3

======================================================================
PSEUDOCODE
======================================================================
RESOLVE CONTACT:
    interfaces := groupPhysicalInterfaces(hit.intervals)
    impact := ImpactSolver.solve(projectile.snapshot, interfaces, targetMotion)

    switch impact.mode:
      Penetration:
        projectile.transition(impact.transition)
        enqueue damage(interface sections)
        enqueue targetImpulse once
        continue flight from epsilon-safe exit position
      Ricochet/Glance:
        projectile.transition(impact.transition)
        ricochetCount += as specified
        enqueue targetImpulse/damage once
        continue flight
      Stop:
        enqueue targetImpulse/damage once
        projectile.dead := true

MULTI-TICK MATERIAL:
    if interval traversal not complete:
        state.contact.progress += pathThisTick
        retain contact state
    else:
        finalize contact exactly once

THREADING / OWNERSHIP RULES
======================================================================

ERROR HANDLING
======================================================================

======================================================================

======================================================================

PERFORMANCE RULES
