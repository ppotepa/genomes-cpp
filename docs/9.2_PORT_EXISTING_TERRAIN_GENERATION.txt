======================================================================
PUBLIC CONTRACTS
======================================================================
1. TerrainGenerator v1-legacy reproduces SOURCE SeededPerlin/FBM plan at selected fixture sample points/fields within explicit float tolerance.

2. Native future TerrainGenerator v2 may improve morphology but cannot overwrite v1 artifact version.

3. Fixture exports contain exact SOURCE commit, seed, map size, resolution and selected heights/normals/statistics.

======================================================================
DATA LAYOUT
======================================================================
Authoritative output remains HeightFieldArtifact from 9.1: row-major contiguous
height samples plus separate derived/material fields.

Generation scratch is separate:
    NoiseContext / seeded octave parameters
    temporary row/tile buffers
    optional normals/material classification scratch

No THREE.BufferGeometry or GPU buffer is stored in terrain semantic output.
Legacy chunk-mesh information is compiled later by 9.4.

All arrays use explicit width/height/stride metadata and checked index:
    index = z * width + x.

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Rows/tiles may generate in parallel because each sample is pure from seed+coordinate; output index, not completion order, defines placement.

======================================================================
ERROR HANDLING
======================================================================
Invalid procedural candidates return ValidationReport/Result. Active world is changed only through generation transaction commit.

======================================================================
DETERMINISM RULES
======================================================================
Legacy fixture parity is independent of thread count. Exact RNG/noise compatibility functions are versioned separately.

======================================================================
PERFORMANCE RULES
======================================================================
Generation computes noise once per height sample at build time; routine runtime sampling uses retained field.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
This chapter creates SOURCE parity fixtures in TARGET/reference and does not change SOURCE.
