======================================================================
PUBLIC CONTRACTS
======================================================================
1. TerrainGenerator produces HeightFieldArtifact from TerrainSpec + SeedPath.
Noise/warp/ridge/continental fields have independent named streams and declared
frequency/amplitude domains.

2. Battlefield and large-world profiles select TARGET parameters, not alternate
legacy algorithms. Profile identity is part of the artifact key.

3. TARGET fixtures contain seed, profile, map size, resolution, selected
heights/normals/statistics and quality thresholds. Imported samples are optional
diagnostics with provenance.

======================================================================
DATA LAYOUT
======================================================================
Authoritative output remains HeightFieldArtifact from 9.1: row-major contiguous
height samples plus separate derived/material fields.

Generation scratch is separate:
    NoiseContext / seeded octave parameters
    temporary row/tile buffers
    optional normals/material classification scratch

No THREE.BufferGeometry or GPU buffer is stored in terrain semantic output.
Chunk-mesh information is compiled later by 9.4.

All arrays use explicit width/height/stride metadata and checked index:
    index = z * width + x.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define TARGET fixtures for battlefield and large-world profiles, including a
    complete modest grid and sparse large-map quality samples.

STEP 2
    Implement deterministic coordinate-addressable noise using named SeedPath
    domains; no sequential compatibility wrapper.

STEP 3
    Implement TARGET FBM/warp/ridge/continental composition and edge shaping,
    using double intermediates where needed for stable results.

STEP 4
    Generate HeightFieldArtifact and validate samples, statistics, slope,
    continuity, drainage suitability and profile-specific quality bounds.

STEP 5
    Freeze one TARGET schema identity and benchmark serial/parallel generation.

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Rows/tiles may generate in parallel because each sample is pure from seed+coordinate; output index, not completion order, defines placement.

======================================================================
ERROR HANDLING
======================================================================
Invalid procedural candidates return ValidationReport/Result. Active world is changed only through generation transaction commit.

======================================================================
DETERMINISM RULES
======================================================================
TARGET field identity is independent of thread count, tiling and job completion
order. Coordinate-addressable streams avoid draw-order coupling.

======================================================================
PERFORMANCE RULES
======================================================================
Generation computes noise once per height sample at build time; routine runtime sampling uses retained field.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
No runtime compatibility terrain generator. Reference terrain may inform
quality bounds but cannot select another implementation path.
