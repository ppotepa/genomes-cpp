PUBLIC CONTRACTS
======================================================================
1. WorldQuerySnapshot pins/read-locks relevant region/index revisions for query batch lifetime; query result includes region/source IDs and revision where needed.

2. APIs: terrainHeight/sample, queryAabb/radius candidates, segment/ray candidates, building lookup, regionAt, loaded/residency metadata.

3. Facade returns broadphase candidates unless method explicitly says narrowPhase. Domain-specific material/LOS decisions remain consumers.

4. Missing/unloaded region returns typed status: Complete, PartialUnloaded, Missing rather than silently treating unknown as empty.

DATA LAYOUT

PSEUDOCODE
======================================================================
QUERY AABB:
    regions := regionsOverlapping(bounds)
    result.completeness := Complete
    for region in stable coord order:
        if !semanticResident(region):
            result.completeness := PartialUnloaded
            continue
        region.staticBvh.query(bounds,out)
        region.dynamicGrid.query(bounds,out)
    dedup
    if stableOrderRequested: sort by stable ID
    return result
