PUBLIC CONTRACTS
======================================================================
1. Each worker owns a local deque: owner pushes/pops local end, thieves steal opposite end. External submissions enter injection queue then are localized by workers.

2. A job with unresolved dependencies is not runnable. DependencyCounter decrements atomically and enqueues continuation exactly once when it reaches zero.

3. JobGraph is runtime scheduling metadata only; domain state must not depend on actual execution order.

4. Priority classes limited to Critical/Normal/Background initially; starvation tests required.

======================================================================
DATA LAYOUT
======================================================================
Use compact value types, explicit ownership, contiguous storage in hot paths, and no hidden shared mutable state.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement bounded or dynamically growing Chase-Lev style deque only if memory model is fully understood; otherwise use proven mutex-protected per-worker deque first and benchmark before lock-free replacement.

STEP 2
    Add steal loop choosing victims via deterministic-free scheduler RNG/permutation; scheduler nondeterminism is allowed because semantic commit is independent.

STEP 3
    Implement dependency continuation node with atomic remaining count and exactly-once enqueue.

STEP 4
    Implement JobGraphBuilder that returns handles; graph cycles must be rejected when statically known or documented unsupported.

STEP 5
    Add fairness rule: after K local jobs, check injection/global/other priorities.

STEP 6
    Benchmark fan-out/fan-in DAG and uneven job durations.

PSEUDOCODE
======================================================================
COMPLETE(job):
    for continuation in job.continuations:
        old := continuation.remaining.fetch_sub(1)
        if old == 1:
            enqueueRunnable(continuation)

WORKER:
    if popLocal(): run
    else if popInjection(): run
    else if stealFromVictim(): run
    else sleep

FAN-IN:
    A,B,C -> D
    D.remaining = 3
    completion(A/B/C) decrements
    transition 1->0 enqueues D exactly once
