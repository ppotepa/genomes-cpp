======================================================================
PUBLIC CONTRACTS
======================================================================
1. LOS request = observer eye point, target aim point, observer/target semantic IDs and query mask. Eye/aim landmarks supplied by domain capability/phenotype, not hardcoded renderer skeleton reads.

2. WorldQuery batch returns first blocking semantic hit; terrain and static/dynamic solids use same revision snapshot. Target/self volumes are accepted/ignored according to query filter.

3. Broadphase false positives do not imply visibility. Exact narrow phase must test real collision/semantic surfaces.

4. Results are batched and indexed back to observer-target pair; ordering does not affect semantics.

5. CPU implementation is authoritative fallback; future GPU result can be advisory/async only after explicit latency/consistency contract.

======================================================================
DATA LAYOUT
======================================================================
LOSRequest/LOSResult contiguous arrays for batch. Result: visible bool, blockerId optional, hitDistance, worldRevision. No per-request heap.

IMPLEMENTATION STEPS

STEP 1
    Define semantic eye/aim capability values from Infantry or generic target bounds; combat module depends on interface/data, not rig renderer.

STEP 2
    Collect LOS requests only for broadphase candidates selected by perception policy.

STEP 3
    Batch terrain segment-heightfield and WorldQuery segment queries; use early nearest blocker.

STEP 4
    Filter self at origin and target hit at end by semantic IDs/tolerances; never blindly ignore same-team world blockers.

STEP 5

======================================================================
PSEUDOCODE
======================================================================
REQUEST BUILD:
    for observer:
        for candidate in candidateList:
            requests.push(eye(observer), aim(candidate), ids)

BATCH:
    parallel_for query batches:
        hit := world.firstSegmentHit(a,b,mask,revision)
        if no hit:
            visible := true
        else if hit.semanticOwner == targetId:
            visible := true
        else if hit.semanticOwner == observerId and hit.distance < selfEpsilon:
            continue query after self
        else:
            visible := false
            blocker := hit.id

OBSERVATION:
    visibleTargets := candidate where los.visible
    stable_sort distance,id

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Queries read immutable world/query snapshot and parallelize batches. Results write indexed array. No world mutation.

======================================================================
ERROR HANDLING
======================================================================
World revision unavailable -> explicit QueryStale/Retry policy; do not assume visible. Nonfinite endpoints rejected.

======================================================================
DETERMINISM RULES
======================================================================
Same snapshot/input yields stable visibility. Tie hit ordering resolved by distance then semantic ID/source priority.

======================================================================
PERFORMANCE RULES
======================================================================
Only run after candidate reduction. Batch memory contiguous. Track requests/accepted/blockers and query source costs.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Use TARGET heightfield/geometry queries with documented blocking and clearance
rules; no sampled compatibility heuristic is retained.
