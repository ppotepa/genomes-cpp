======================================================================
PUBLIC CONTRACTS
======================================================================
1. Disk artifacts/saves use atomic replace and checksum/version validation. Partial temp files never masquerade as valid committed artifact.

2. Artifact cache corruption is recoverable when artifact is reproducible: quarantine/delete invalid entry and regenerate from canonical inputs. Do not regenerate save-only mutable state.

3. Failed START NEW/load keeps prior active world if available and disposes partial candidate resources.

4. Optional render/compute backend failure may fall back/reinitialize where architecture supports; authoritative simulation is checkpointed/paused safely during device recovery, never continues writing presentation handles.

5. Fatal invariant failure produces diagnostic context: build/dependency versions, subsystem, tick, world seed/region, last errors/log ring where privacy-safe.

======================================================================
DATA LAYOUT
======================================================================
Artifact header checksum/content hash, atomic temp path, quarantine metadata. RecoveryResult typed category/action. DiagnosticContext compact IDs not raw sensitive data.

======================================================================
PSEUDOCODE
======================================================================
READ ARTIFACT:
    header := read fixed bounded header
    validate magic/version/declaredSize <= limit
    bytes := readExact(declaredSize)
    verify checksum/hash
    if invalid and reconstructible:
        quarantine(path)
        result := regenerate(canonicalKey)
        if second failure: return error
    else if save mutable:
        return CorruptSave error

START_NEW:
    old := activeWorld
    candidate := build transaction
    if any stage fail:
        candidate.dispose()
        activeWorld := old
        return error
    commit candidate
    retire old after readers drain

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Recovery state serialized per artifact key/world transaction; avoid two workers repeatedly regenerating same corrupt cache key. Diagnostics thread-safe/ring buffered.

======================================================================
ERROR HANDLING
======================================================================
Explicit typed categories: CorruptData, UnsupportedVersion, ChecksumMismatch, IO, ResourceInit, RecoveryLoopPrevented. No catch-all ignore.

======================================================================
DETERMINISM RULES
======================================================================
Regenerated procedural artifact uses same canonical inputs/version; quarantine timestamp not part of semantic content.

======================================================================
PERFORMANCE RULES
======================================================================
Validation linear in artifact bytes; use streaming hash/checksum. Recovery is exceptional path, not hot-loop optimization.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Strengthens native reliability; SOURCE rollback ideas preserved.
