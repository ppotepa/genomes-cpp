======================================================================
PUBLIC CONTRACTS
======================================================================
1. RubbleField grid cell stores total solid volume plus compact per-material mixture. World surface height = baseTerrainHeight + rubbleHeight(volume, cellArea, packingFactor). Material volumes sum to total within numeric tolerance.

2. Tile key from floor(worldXZ/tileSize). Field has max retained tiles/bytes. Capacity pressure never discards new volume: eligible low-volume/cold tiles are merged into nearest compatible retained tile or explicit world-stream spill artifact; with one-tile local budget clamp/merge policy is deterministic.

3. Deposit accepts material-volume map, world point, spread radius/impact speed and relaxation iterations. Remove/excavate returns exact removed material mix for re-ejection/accounting.

4. Slope relaxation moves volume between neighbor cells using bounded iterations while preserving each material fraction/total; no negative volume.

5. Queries: rubbleHeight, surfaceHeight(base provider), rubbleSlope, movementCost, cover, materialMix, segment/surface hit. Broadphase checks nonempty tile before cell sampling.

6. Dirty tile produces backend-neutral static collision surface recipe (heightfield preferred; low-poly mesh/cuboid conservative fallback) and NavDirtyBounds.

======================================================================
DATA LAYOUT
======================================================================
Tile = fixed cell grid (e.g. 8x8 at default) with float/double total volume and small material mixture storage. Prefer fixed known material slots/compact sparse pairs; exact accumulation may use double at commit then quantize/store per policy.

======================================================================
PSEUDOCODE
======================================================================
DEPOSIT:
    weights := cellsWithin(radius) with nonnegative kernel
    normalize sum(weights)
    for cell in stable order:
        for material m:
            dv := requested[m]*weight
            cell.material[m] += dv
            cell.total += dv
    mark tiles dirty

RELAX ITERATION:
    delta := zero scratch
    for cell:
        for lower neighbor stable:
            transfer := boundedSlopeExcess(cell,neighbor)
            mix := cell.material / cell.total
            delta[cell] -= transfer*mix
            delta[neighbor] += transfer*mix
    apply delta
    assert conservation/no negatives

OVERFLOW:
    if new tile and capacity full:
        victim := eligible lowest-volume/cold stable tie
        merge victim material/volume to nearest compatible retained tile
        free victim
    insert new requested tile

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Deposits from jobs become per-tile commands; commit partitions by tile so separate tiles can process in parallel. Relaxation within tile uses scratch/double buffer. Cross-tile border transfer uses staged halo commands and stable commit.

======================================================================
ERROR HANDLING
======================================================================
Nonfinite/negative deposit rejected. Capacity with no eligible merge target uses configured persistent spill/forced merge policy and reports metric; never drops volume.

======================================================================
DETERMINISM RULES
======================================================================
Cell/tile mapping uses floor. Deposit/relax order stable or uses commutative double accumulators with stable final application. Visual chunk generation never changes field.

======================================================================
PERFORMANCE RULES
======================================================================
Tile sparse map, dirty-only collision/nav rebuild, near-detail rendering separate. Benchmark 1/100/1000 dirty tiles, deposit rate, relaxation.
