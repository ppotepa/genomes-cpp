======================================================================
PUBLIC CONTRACTS
======================================================================
1. Default TARGET rubble profile:
    cellSize          = 0.5 m
    tileSize          = 4.0 m
    cellsPerTile      = 8 x 8
    maxTiles          = 256
    maxChunkInstances = 1024
    maxSlope          = 0.78

These values are configurable/versioned rather than hidden magic assumptions.

2. Each cell stores total solid volume and per-material volume. Derived height = volume/(cellArea*packing model) over base terrain height. Mixed materials remain accounted individually.

3. Deposit/remove/relax operations conserve total and per-material volume except explicitly ejected/removed packets recorded in the ledger.

4. Tile capacity overflow never modulo-wraps or discards volume.

TARGET capacity behavior:
    if tile count reaches 256:
        prefer removal of a microscopic tile only when total < .003;
        otherwise merge the lowest-volume source tile into its nearest remaining
        tile;
        one-tile edge case reuses the nearest/only tile rather than dropping the
        incoming deposit.

The merge metric is deterministic and must preserve per-material volume, avoid
world-coordinate modulo wrapping and minimize spatial displacement.

5. Logical field updates happen immediately; dirty tile render/physics compilation is deferred/batched. Query APIs read logical state.

6. Expose heightAt, surfaceHeightAt, pileSlopeAt, movementCostAt, coverAt, sampleNavigation and ballistic broadphase/part sampling.

PSEUDOCODE
======================================================================
CELL:
    cx := floor(x / cellSize)
    cz := floor(z / cellSize)
    tx := floorDiv(cx, cellsPerTile)
    tz := floorDiv(cz, cellsPerTile)
    localX := floorMod(cx, cellsPerTile)
    localZ := floorMod(cz, cellsPerTile)

DEPOSIT:
    weights := deterministic kernel around impact cell
    normalize weights
    for target cell in stable order:
        q := volume * weight
        cell.total += q
        cell.material[mat] += q
        mark tile dirty

RELAX:
    repeat boundedIterations:
        transfers := []
        for neighboring cell pair in canonical edge order:
            if slope > reposeThreshold:
                q := boundedTransfer(...)
                transfers.push(pair,q,mixture)
        apply transfers after scan
    assert material/total conservation

SURFACE:
    pileHeight := totalVolume / (cellArea * packingFactor)
    return terrainBaseHeight + pileHeight

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Different tiles can update in parallel when operations are prepartitioned. Cross-tile transfers use command buffers and deterministic merge, not unordered atomics.

======================================================================
ERROR HANDLING
======================================================================
Invalid negative deposit -> InvalidArgument. Capacity cannot preserve volume -> hard failure/transaction rollback, never silent discard. Missing terrain provider defaults only if owning world explicitly configured flat base.

======================================================================
DETERMINISM RULES
======================================================================
floor/floorMod specified for negatives; dirty/merge order stable; generated near-detail later derives from tile seed/state, not frame RNG.

======================================================================
PERFORMANCE RULES
======================================================================
Queries use tile broadphase; empty tiles skip narrow sampling. Dirty rebuild batches. Tile arrays fixed/contiguous for cache locality.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET conservation, navigation and surface invariants define behavior. Imported
rubble samples are diagnostic only; visual chunk placement is non-semantic.
