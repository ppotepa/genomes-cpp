======================================================================
PUBLIC CONTRACTS
======================================================================
1. ZoneField is raster/field artifact with Centre/Urban/Suburb/Rural plus extensible land-use metadata; classification derives from accessibility, center attraction, terrain/hydrology and development params.

2. Half-edge graph uses only planar same-level road segments after intersections are registered. Outgoing half-edges sorted by robust atan2 angle with stable ID tie.

3. Face walk marks directed half-edges; exterior face rejected by signed area/orientation/bounds policy. Block polygon then offsets inward by road ROW/setback policy using robust polygon backend.

4. Block IDs derive from canonical cycle (rotate vertex/edge stable IDs to minimal lexicographic representation), not discovery order.

======================================================================
DATA LAYOUT
======================================================================
Graphs use contiguous node/edge arrays with stable IDs and adjacency ranges; fields are grid/raster artifacts; polygons use engine geometry types.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Generate ZoneField cells in parallel from immutable city/road/hydrology fields.

STEP 2
    Build directed half-edge adjacency from active level-0 edges.

STEP 3
    Sort outgoing edges by angle then RoadEdgeId.

STEP 4
    Walk every unvisited directed half-edge using fixed previous/next orientation rule from 0.5; compute face polygon.

STEP 5
    Reject exterior/tiny/invalid faces and canonicalize BlockId.

STEP 6
    Apply ROW inset/road corridor subtraction through geometry backend; validate simple buildable block polygons.

======================================================================
PSEUDOCODE
======================================================================
FACE WALK:
    start := halfEdge(u,v)
    cur := start
    do:
        visited.add(cur)
        polygon.push(position(cur.from))
        outgoing := sortedAdj[cur.to]
        reverseIndex := find edge to cur.from
        cur := outgoing[(reverseIndex - 1 + count) % count] // chosen orientation
    while cur != start
    area := signedArea(polygon)
    classify exterior/interior
