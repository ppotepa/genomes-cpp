PUBLIC CONTRACTS
======================================================================
1. Intersection result is classified: None, Proper, EndpointTouch, CollinearOverlap. Generic primitive does not hide endpoint semantics.

2. orient2d public API has fast and robust variants; topology algorithms default to robust filtered/exact predicate implementation approved by this chapter.

3. Aabb2 uses min/max XZ with explicit empty state and expand/overlap/contains.

PSEUDOCODE
======================================================================
INTERSECT:
    o1 := orient(a,b,c)
    o2 := orient(a,b,d)
    o3 := orient(c,d,a)
    o4 := orient(c,d,b)
    if strict opposite signs on both pairs:
        solve t,u -> Proper
    if any orientation zero:
        classify endpoint/collinear using projection
    else None
