1. HOW PROGRESS IS MEASURED
======================================================================

This file tracks two different metrics.

A. MANUAL AUTHORING PROGRESS

A chapter counts as authored when:
    file exists,
    STATUS is READY,
    it satisfies the 0.0 completeness contract.

This is NOT implementation progress.

B. NATIVE IMPLEMENTATION PROGRESS

A chapter counts as implemented only after:
    required source changes exist,
    required tests pass,
    acceptance criteria pass,
    chapter is verified.

At the current baseline no native implementation chapter has been executed in
ppotepa/genomes-cpp yet.
