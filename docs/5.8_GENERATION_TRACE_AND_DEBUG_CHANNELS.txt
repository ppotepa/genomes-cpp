======================================================================
PUBLIC CONTRACTS
======================================================================
1. Trace disabled path must be near-zero overhead and may compile out payload capture while preserving counters if configured.

2. Channels are stable IDs: Candidates, Rejections, Scores, Geometry, Timing, RNG, Validation. Domain modules may add namespaced channel IDs.

3. Trace buffer has byte/event budget and overflow policy DropOldest/DropNewest/SummaryOnly selected by caller; production default disabled.

4. Trace events carry stable semantic object/node IDs and deterministic logical sequence assigned by producer stage, not wall-clock ordering.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define compact TraceEvent header + tagged payload references stored in transaction trace arena.

STEP 2
    Implement isEnabled(channel) fast branch and emit APIs.

STEP 3
    Implement per-job trace buffers merged by stable node/batch/event sequence after jobs finish.

STEP 4
    Add debug geometry primitives Line/Polyline/Polygon/Point with semantic coordinates only, no renderer objects.

STEP 5
    Serialize traces to canonical JSON/binary for proc viewer.

STEP 6
    Benchmark disabled path and bounded 100k event capture.

======================================================================
PSEUDOCODE
======================================================================
EMIT:
    if !config.enabled(channel): return
    event.logicalKey := {nodeId,batchIndex,localSequence}
    localBuffer.push(event) or apply overflow policy

MERGE:
    gather job-local buffers
    stableSort by logicalKey
    enforce global byte budget
    publish immutable GenerationTrace
