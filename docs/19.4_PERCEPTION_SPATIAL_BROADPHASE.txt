======================================================================
PUBLIC CONTRACTS
======================================================================
1. Perception broadphase queries only neighboring dynamic spatial cells intersecting perception radius; never loops all combatants for each observer.

2. Candidate filter stages cheapest-to-expensive: alive/team/category -> squared range -> horizontal/3D FOV -> coarse occlusion hints optional -> exact LOS in next chapter.

3. Perception source/target positions and headings are authoritative simulation snapshots, not render transforms.

4. Candidate output stable sorted by observer-defined key (distance then EntityId) when downstream behavior needs deterministic nearest order.

5. Spatial cell size/profile benchmarked; dense worst-case remains bounded by local density and optional candidate budget with explicit truncation policy.

======================================================================
DATA LAYOUT
======================================================================
Observer batch arrays + scratch Candidate{targetId,distanceSq,relative vector}. DynamicGrid from engine spatial stores EntityId and coarse bounds/category/team masks.

======================================================================
PSEUDOCODE
======================================================================
for observer in batch:
    cells := grid.cellsOverlappingCircle(observer.pos, range)
    candidates.clear
    for cell in cells:
        for targetId in cell:
            if targetId == observer: continue
            if team[target] == team[observer]: continue
            if !alive[target]: continue
            d2 := distanceSq(pos[target], pos[observer])
            if d2 > rangeSq: continue
            dir2 := normalizeXZ(pos[target]-pos[observer])
            if dot(dir2, forward(observer.heading)) < cosHalfFov: continue
            addUnique(targetId,d2)
    stable_sort by d2,targetId
    output range
