======================================================================
PUBLIC CONTRACTS
======================================================================
1. Global semantic position uses double meters or integer fixed world cell + local float; initial canonical API uses Vec3d WorldPosition.

2. RegionCoord is signed integer (x,z, optional layer) computed with floor; RegionId derives deterministically from WorldId + coord, not load order.

3. RegionLocalPosition is float relative to region origin. Conversions are explicit and round-trip within documented precision.

4. Region size is configuration/schema data, not constexpr hidden across code; initial default may be selected later by benchmark.

PSEUDOCODE
======================================================================
REGION COORD:
    rx := floor(global.x / regionSize)
    rz := floor(global.z / regionSize)

ORIGIN:
    return (rx*regionSize, 0, rz*regionSize)

LOCAL:
    return float(global - origin(coord))

ID:
    bytes := canonical(WorldId, rx, rz, layer)
    return RegionId(stableHash(bytes))
