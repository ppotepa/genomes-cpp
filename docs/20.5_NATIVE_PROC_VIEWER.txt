======================================================================
PUBLIC CONTRACTS
======================================================================
1. Viewer consumes public artifacts/debug traces/diagnostic services; it cannot require generators to contain UI/render code.

2. Modes: terrain/hydrology, roads/city, building, vegetation, destruction/ballistics, Infantry/appearance/animation, world/spatial/nav/render diagnostics.

3. Every mode can select seed/version/parameters, regenerate cancellably, inspect stage timings/validation and overlay semantic data.

4. Headless exporters and viewer use same generator/service APIs. UI changes do not alter seed identity except declared input parameters.

5. Viewer must expose parity fixture loading/comparison and artifact/source provenance where available.

======================================================================
DATA LAYOUT
======================================================================
Viewer state contains selected generator descriptor/request/artifact handles and presentation-only camera/UI. Generated semantic artifact owned by ArtifactStore/reference counts.

PSEUDOCODE
======================================================================
REGENERATE:
    cancel(currentGenerationGroup)
    request := UI -> GenerationRequest
    candidate := proc.submit(request)
    while pending:
        UI shows progress from telemetry
    if candidate.valid:
        viewerArtifact := candidate.commitToViewerScope()
        release old artifact
    else:
        show ValidationReport, keep old

DRAW:
    snapshot := viewerPresentation.extract(selectedArtifact, debugFlags)
    renderGraph.execute(snapshot)
    panels.read immutable diagnostic snapshots

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
UI/render thread never runs heavy generators directly. Jobs common pool. Diagnostics copied/snapshotted safely.

======================================================================
ERROR HANDLING
======================================================================
Failed generation displays report and retains previous valid artifact. Missing optional domain module hides mode with reason.

======================================================================
DETERMINISM RULES
======================================================================
Seed/params explicitly shown and exportable; camera/debug toggles do not change artifact hash.

======================================================================
PERFORMANCE RULES
======================================================================
Viewer diagnostics can be expensive but must be opt-in/lazy. No hidden full CPU skin/bounds scan when panel closed.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
SOURCE labs remain reference; native viewer becomes primary parity/manual acceptance environment after feature coverage.
