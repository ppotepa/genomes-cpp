3. DILIGENT DEBUG — SAM BUILD
------------------------------
PowerShell, z katalogu repo:

    .\run-diligent.ps1 -BuildOnly

Alternatywnie, w juz przygotowanym developer shell:

    cmake --preset dev-debug
    cmake --build --preset dev-debug --target genomes_game

Istotne ustawienia:
    GENOMES_RENDER_BACKEND=DILIGENT
    GENOMES_ENABLE_DILIGENT=ON
Nazwa profilu DILIGENT jest jedyną aktywną ścieżką renderującą.
Target genomes::render_diligent zawiera juz NOWA implementacje z tego pakietu.
Nie jest to powrot do starego monolitycznego kodu.

6. DETERMINISTYCZNY PNG + JSON
------------------------------
Przyklad pojedynczego capture (uzyj NOWEJ sciezki):

Powstaja:
    artifacts/diligent-front-01.png

identyfikatory/revision siatek, skeleton/pose revision i wagi morphow.

Kazdy przypadek ma osobny PNG, JSON i log. Skrypt odmawia uzycia istniejacego
katalogu wyjsciowego. Stworzenie plikow NIE oznacza ich akceptacji wizualnej.
