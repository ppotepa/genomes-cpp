======================================================================
PUBLIC CONTRACTS
======================================================================
1. Save separates immutable/reconstructible world recipe metadata from mutable authoritative state. Do not dump renderer/physics backend memory.

2. Save header includes game/schema version, world generator versions, root seed, required catalog versions and content hashes.

3. Procedural artifact may be referenced by content key and regenerated only if exact compatible generator/catalog versions exist; otherwise packaged artifact or migration required.

4. Mutable state includes entity IDs/components needed for gameplay, destroyed/modified structures/rubble, orders, inventories/equipment, world tick and region persistence state.

5. Load is transactional: parse/validate/migrate into candidate WorldSaveModel, resolve artifacts, then create/commit world. Corrupt save never partially overwrites active world.

======================================================================
DATA LAYOUT
======================================================================
Chunked/versioned package with header/table + typed sections/regions, checksums/content hashes. Exact binary format chosen by Stage 2 schema policy; unknown optional chunks skippable only by declared compatibility.

======================================================================
PSEUDOCODE
======================================================================
SAVE:
    snapshot := simulation.freezePersistentSnapshot()
    package.header := versions + seed + tick + hashes
    for region in stable RegionId order:
        write recipe/artifact refs
        write mutable deltas/entities/destruction
    finalize table/checksums
    write temp
    validate/readback optional
    atomicReplace(destination,temp)

LOAD:
    bytes := read bounded
    header := validateHeader
    model := parse all sections to candidate
    migrate model if supported
    validate catalogs/artifacts
    candidateWorld := instantiate(model)
    if success: commit candidate
    else: keep active world

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Save snapshot created at simulation barrier; serialization/compression/IO may run worker threads on immutable snapshot. Load parse parallel chunks then deterministic commit.

======================================================================
ERROR HANDLING
======================================================================
Corruption/checksum/version/catalog mismatch typed errors. Unsupported migration explicit. Never best-effort skip authoritative unknown data.

======================================================================
DETERMINISM RULES
======================================================================
Canonical ordering for hashes/save if required. Runtime transient handles remapped from stable semantic IDs during load.

======================================================================
PERFORMANCE RULES
======================================================================
Chunk regions, stream IO, avoid pausing long serialization; snapshot copy-on-write/delta optimization later only after correctness.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Legacy browser has no full save format; current Equipment JSON informs semantic fields but native schema is new/versioned.
