======================================================================
PUBLIC CONTRACTS
======================================================================
1. FlowField scoped to nav tile/region/corridor and goal set; stores integration cost + direction. It never ignores impassable nav semantics.

2. CPU reference uses deterministic integer/fixed or ordered priority propagation where exactness required. GPU implementation may use iterative wavefront/Jacobi-style relaxation with convergence criterion and is derived.

3. Field key includes nav revision, cost profile, goal set hash and bounds. Dirty nav invalidates affected fields.

4. Agents sample flow direction locally but may fall back to Detour/local path if field unavailable/invalid or dynamic constraints require.

5. Do not generate one field per single agent when goal sharing is absent.

======================================================================
FlowFieldDescriptor, IntegrationCost grid, Direction encoded normalized/vector index, goal cell set, revision/key. GPU ping-pong atlas layers.

IMPLEMENTATION STEPS

STEP 1

STEP 2
    Derive direction by descending neighboring integration cost with stable tie-break.

STEP 3
    Implement GPU iterative relaxation/ping-pong with obstacle mask and bounded iterations/convergence flag.

STEP 4
    Compare CPU/GPU reachability/directions/cost tolerance on small grids.

STEP 5
    Cache/share by field key among squads/agents and invalidate on nav revision.

STEP 6
    Benchmark 256²..2048² grids and many-agent sampling versus repeated path requests.

PSEUDOCODE
======================================================================
CPU INTEGRATION:
    costs := INF
    priorityQueue goals cost=0
    while queue:
        c := pop min (cost, cellId)
        for neighbor traversable:
            ncost := costs[c] + moveCost(c,neighbor)
            if ncost < costs[neighbor]:
                costs[neighbor] := ncost
                push

DIRECTION:
    best := current
    for neighbor in fixed order:
        if cost[neighbor] < cost[best]:
            best := neighbor
    dir := normalize(center(best)-center(current))

GPU RELAX:
    ping := initial goals/INF
    repeat until maxIterations or convergence:
        pong[cell] := min(ping[cell], neighbor costs + edge)
        set changed flag
        swap

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
CPU fields job-parallel across fields/tiles; GPU async through compute service. Agents read completed immutable field revision.

======================================================================
ERROR HANDLING
======================================================================
Unreachable cell explicit Invalid/zero direction; GPU no convergence -> discard/fallback CPU/path.

======================================================================
DETERMINISM RULES
======================================================================
CPU reference tie-break fixed. GPU approximate field advisory; discrete decisions can fall back if mismatch matters.

======================================================================
PERFORMANCE RULES
======================================================================
Field creation amortized across many agents. Benchmark creation+sampling total vs shared route/local A*.
