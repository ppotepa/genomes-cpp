======================================================================
GOAL
======================================================================
Create a generic GPU-resident field-atlas subsystem for large 2D/2.5D world grids such as threat, influence, visibility hints, flow cost, terrain derivatives and rubble overlays. The atlas is derived/advisory by default and must not become hidden authoritative gameplay state.

======================================================================
PUBLIC CONTRACTS
======================================================================
1. FieldAtlas is tiled/layered logical data with FieldId, resolution, world transform, format, revision and authority class {DerivedAdvisory, DerivedAuthoritativeWithCPUFallback}.

2. World-to-cell mapping is explicit and stable; atlas texture/buffer representation is backend detail behind ComputeService.

3. Updates are dirty-rect/tile based. CPU semantic deltas upload compactly; full clear/rebuild only when required.

4. Readback is explicit asynchronous request with revision/fence; no CPU code may read GPU field synchronously through hidden stall.

5. Field algorithms must declare whether one-frame/one-tick stale data is acceptable.

======================================================================
DATA LAYOUT
======================================================================
FieldAtlasDescriptor + FieldRegion, logical tile dimensions, revisioned dirty-rect queue and explicit readback tokens behind render/compute module. CPU metadata is compact and serializable only as configuration, not GPU contents by default.

PSEUDOCODE
======================================================================
WORLD_TO_CELL:
    u := (x-originX)/cellSize
    v := (z-originZ)/cellSize
    ix := floor(u); iz := floor(v)

UPDATE:
    for semantic dirty event:
        tile := atlas.tile(event.bounds)
        dirty.set(tile)
    upload dirty source buffers
    dispatch kernels only dirty/expanded tiles
    atlas.revision++

READBACK:
    request(revision, region):
        copy GPU region -> staging
        signal fence
        return token
    poll token without blocking simulation

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
CPU metadata ownership compute service; GPU queue sync via RenderGraph/ComputeService fences. Do not submit same queue concurrently outside Diligent synchronization contract.

======================================================================
ERROR HANDLING
======================================================================
Unsupported format/size -> capability error and CPU fallback if contract allows. Stale readback tagged revision, never mistaken current.

======================================================================
DETERMINISM RULES
======================================================================
Derived advisory fields may differ slightly by GPU; authoritative decisions must either use CPU canonical result or explicit tolerance/versioned GPU contract.

======================================================================
PERFORMANCE RULES
======================================================================
Avoid full-map uploads, synchronous readback and unnecessary barriers. Multiple queues only if profiler proves overlap; Vulkan queues require explicit synchronization.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Native-only infrastructure; SOURCE has no equivalent GPU field system.
