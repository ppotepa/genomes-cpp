======================================================================
PUBLIC CONTRACTS
======================================================================
1. DebugDraw receives semantic primitives Point/Line/Polyline/AABB/OBB/Polygon/Text marker with world coordinates and lifetime frames/seconds; producers never create GPU buffers.

2. Debug channels are bitset/stable IDs and can be disabled before payload allocation where possible.

3. GPU profiler wraps RenderGraph passes with timestamp queries when capability supports it; reports pass GPU duration, CPU record duration and queue.

4. Profiler readback is delayed/nonblocking; never stall current frame waiting for timestamp results.

======================================================================
DATA LAYOUT
======================================================================
Public renderer-facing handles are compact generational values. Backend objects are private implementation data.

======================================================================
PSEUDOCODE
======================================================================
DEBUG EMIT:
    if !channelEnabled: return
    local.commands.push(primitive)

FRAME:
    merged := gather local commands
    encode vertices into frame upload buffer
    RenderGraph.addPass(DebugDraw)

PROFILE PASS:
    writeTimestamp(begin)
    execute pass
    writeTimestamp(end)
    resolve on frame N+k when ready

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Render backend owns GPU objects. Simulation never touches Diligent objects. Render extraction consumes immutable snapshots and stages uploads.

======================================================================
ERROR HANDLING
======================================================================
Device/shader/resource failures return typed errors with diagnostics; no silent fallback that changes correctness or feature policy.

======================================================================
DETERMINISM RULES
======================================================================
Presentation may be frame-order nondeterministic, but stable semantic IDs map to persistent GPU records; no render result feeds authoritative gameplay unless explicitly specified.

======================================================================
PERFORMANCE RULES
======================================================================
Minimize CPU submission, resource churn, state changes and readbacks. All GPU features are capability/benchmark driven.
