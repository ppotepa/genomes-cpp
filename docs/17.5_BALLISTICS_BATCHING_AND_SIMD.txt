======================================================================
PUBLIC CONTRACTS
======================================================================
1. Canonical semantic ProjectileState remains serializable AoS; hot runtime storage may be SoA/chunked but conversion is lossless.

2. Batch scheduler partitions active projectile IDs into stable ranges/chunks; worker completion order does not define event order.

3. SIMD applies only to homogeneous flight math candidates (position/velocity/drag broad phases). Branch-heavy contact resolution may remain scalar.

4. World query batching groups segment/AABB requests without weakening exact narrow-phase surfaces.

5. Optimization gate requires scalar reference parity for seeded fixtures and 1-thread/N-thread runs.

PSEUDOCODE
======================================================================
PARALLEL FLIGHT:
    chunks := storage.activeChunks(grain)
    parallel_for chunk in chunks:
        localEvents := scratch.events
        for lane/entity in chunk:
            integrateFlightCandidate(...)
            broadphaseRequests.push(segment)
        hits := worldQuery.batchSegments(broadphaseRequests)
        for entity in stable local order:
            resolve candidate/hit
            localEvents.push(...)

    barrier
    allEvents := concatenate(workerEvents)
    stable_sort(allEvents, by tick, projectileId, localSequence)
    commit(allEvents)

COMPACTION:
    at safe commit:
        move live records to dense slots
        update handle generations/index map
        never expose raw array pointer as semantic identity

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Disjoint chunks owned by one worker. Cold catalog immutable. Structural effects via events only.

======================================================================
ERROR HANDLING
======================================================================
Storage capacity rejection explicit. SIMD unsupported -> scalar path, not build failure. Any parity mismatch disables optimized path in production profile until fixed.

======================================================================
DETERMINISM RULES
======================================================================
Stable semantic IDs survive compaction. Parallel event sorting restores semantic order. Floating SIMD path must meet numeric tolerance/behavioral fixtures; exact where required.

======================================================================
PERFORMANCE RULES
======================================================================
Report projectiles/s and frame/tick ms by workload and thread count. Watch memory bandwidth, false sharing and query cost. No per-projectile task scheduling.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Do not preserve JS object arrays. Preserve outcomes and traces. SIMD optimization is native-only.
