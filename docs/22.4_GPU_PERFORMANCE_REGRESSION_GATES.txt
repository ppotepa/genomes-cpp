======================================================================
PUBLIC CONTRACTS
======================================================================
1. GPU baseline keyed by exact GPU/driver/API/backend/render profile/resolution/scene scenario and dependency/shader version.

2. Metrics: GPU frame median/p95/p99, key pass timestamps, visible/culled instances, draw/dispatch count, triangles/meshlets where available, uploads/readbacks, VRAM estimate, async compute overlap/queue waits.

3. Render correctness/image/golden checks run independently; a faster broken renderer cannot pass performance gate.

4. Async compute accepted only if total frame/workload improves; separate queue may contend or map same hardware.

5. CUDA baseline only on matching NVIDIA profile and never substitutes Diligent cross-vendor baseline.

DATA LAYOUT

GPU benchmark result schema with backend device identifiers/driver and per-pass metrics. Baseline update requires rationale/change reference.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define controlled representative render scenes from 22.1 and fixed output resolution/profile.

STEP 2
    Insert GPU timestamp queries/pass markers around render graph and compute passes without excessive synchronization.

STEP 3
    Collect culling/indirect statistics and upload/readback bytes.

STEP 4
    Run D3D12/Vulkan paths where supported on reference machines; compare capability-equivalent features.

STEP 5
    Measure async compute ON/OFF for field/skinning/culling workloads and reject if total regresses beyond policy.

STEP 6
    Implement baseline checker with variance/warmup and driver/profile fingerprint.

STEP 7
    Record visual correctness hash/image reference before accepting timing baseline.

======================================================================
PSEUDOCODE
======================================================================
RUN GPU SCENARIO:
    warm shader/pipeline caches per declared warm profile
    for frame in measurement window:
        begin GPU timestamps
        renderGraph.execute
        collect pass queries deferred
    compute frame/pass percentiles
    verify scenario semantic + visual acceptance
    compare only to matching device/backend baseline

ASYNC A/B:
    A := measure(same scene, asyncCompute OFF)
    B := measure(same scene, asyncCompute ON)
    choose default only if B total frame/workload wins with stable margin

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Timestamp readback deferred; no per-pass CPU wait. Queue ownership/sync accounted in total.

======================================================================
ERROR HANDLING
======================================================================
Driver/device mismatch report no-baseline instead of false fail. GPU query overflow/incomplete run invalid.

======================================================================
DETERMINISM RULES
======================================================================
Visual exactness may vary backend; baseline uses appropriate image metric/reference and authoritative simulation hash fixed.
