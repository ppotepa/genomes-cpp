======================================================================
PUBLIC CONTRACTS
======================================================================
1. Region semantic lifecycle state is separate from render/physics/nav residency bits. A region may have semantic Metadata with no GPU data.

2. RegionRecord is stable metadata keyed by RegionId; large artifact payloads referenced by handles/fingerprints, not embedded.

3. Mutations occur through RegionDatabase writer/command path; read snapshots allow lock-light concurrent queries.

4. Lifecycle transitions are validated by explicit state machine table.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.

======================================================================
PSEUDOCODE
======================================================================
TRANSITION(id,to):
    record := mutableLookup(id)
    if !validTransition(record.state,to): fail
    record.state := to
    record.revision += 1

READ SNAPSHOT:
    snapshot := database.acquireReadSnapshot()
    record := snapshot.find(id)
    // immutable for snapshot lifetime
