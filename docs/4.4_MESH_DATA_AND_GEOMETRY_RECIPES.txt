======================================================================
PUBLIC CONTRACTS
======================================================================
1. MeshData owns CPU arrays: positions, normals, tangents, UV sets, colors, indices, submesh ranges, bounds. Attribute presence is explicit.

2. GeometryRecipe is higher-level deterministic semantic description referencing primitives/curves/material slots; compiler turns recipe into MeshData.

3. Index width is explicit UInt16/UInt32; compiler upgrades when vertex count requires.

4. Mesh validation checks finite values, index bounds, submesh ranges, attribute counts and optional manifold requirements per caller.

======================================================================
DATA LAYOUT
======================================================================
Prefer compact value types, contiguous hot data and explicit ownership.

======================================================================
PSEUDOCODE
======================================================================
VALIDATE MESH:
    n := positions.size
    for attribute enabled:
        require attribute.size == n
    for index in indices:
        require index < n
    for submesh:
        require range inside indices
    require all finite
    return report

COMPILE RECIPE:
    for operation in recipe.operations in stable order:
        emit operation into MeshBuilder
    validate
    return MeshData
