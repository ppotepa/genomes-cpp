======================================================================
PUBLIC CONTRACTS
======================================================================
1. HydrologyArtifact contains water mask/field, river centerlines or graph, width/depth metadata, floodplain distance/mask and drainage/flow field where generated.

2. Hydrology mode: Off, SeededOptional, Forced. SeededOptional probability/placement derives from semantic seed path, not city generation attempt order.

3. Water distance query is accelerated by raster distance field and/or spatial centerline index; road/building code does not rescan all river segments.

4. Terrain carving/modification policy explicit: semantic hydrology can either provide terrain patch to generation DAG or overlay water; v1 must match chosen city pipeline order.

======================================================================
DATA LAYOUT
======================================================================
HydrologyArtifact uses separate contiguous raster fields aligned to terrain or a
declared coarser grid:

    elevation/reference height
    flowDirection or downstream-cell index
    flowAccumulation
    wetness/water mask
    floodplain/distance field where generated

RiverGraph is separate compact graph data:
    RiverNode[]
    RiverEdge[]
    polyline point ranges
    width/depth/flow metadata
    stable IDs

Raster cells never own graph objects. River polylines reference ranges in
contiguous point storage. All fields carry grid transform, dimensions, revision
and generator version.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Port simple seeded river path relation from procedural-city as compatibility baseline fixture.

STEP 2
    Define raster water/flood fields aligned to terrain/city field grid with explicit cell size.

STEP 3
    Implement deterministic river centerline sampling/smoothing and widths; validate self-intersection/terrain bounds.

STEP 4
    Generate TerrainPatch for channel carve if enabled before downstream city cost fields.

STEP 5
    Build distance transform/spatial index for waterDistance(x,z).

STEP 6
    Export selected SOURCE city hydrology seeds for none/through/adjacent cases.

======================================================================
PSEUDOCODE
======================================================================
GENERATE:
    mode := spec.mode
    if SeededOptional and seed.child("river-present").uniform01 > probability:
        return emptyHydrology
    relation := choose relation from seed
    centerline := generate/smooth path across world bounds
    widths := per-node deterministic samples
    rasterize water mask
    compute flood distance/field
    optional terrainPatch := carve(centerline,widths)
    validate
    publish

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Raster rows and distance-field stages parallelize after centerline freeze; each stage is deterministic by cell index.

======================================================================
ERROR HANDLING
======================================================================

======================================================================

======================================================================
PERFORMANCE RULES
