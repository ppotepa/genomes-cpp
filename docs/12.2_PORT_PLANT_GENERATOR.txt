======================================================================
PUBLIC CONTRACTS
======================================================================
1. PlantGenerator stages: genome normalization -> recursive/iterative skeleton -> wood geometry recipe -> foliage cluster recipe -> bounds/metadata -> LOD recipes.

2. Recursive branch growth must be bounded by species depth/segment/node budgets and be cancellable every bounded segment count.

3. Serial/parallel/asynchronous execution produces same semantic skeleton/buffers for same version.

4. Shared trunk/wood/foliage prototype cache ownership uses artifact cache, not hidden static maps.

======================================================================
DATA LAYOUT
======================================================================
Generator scratch:
    append-only BranchNode/Segment arrays
    generation stack/queue
    local RNG streams by semantic branch ID
    temporary foliage anchors
    GeometryRecipe builders

Published output:
    immutable PlantPrototypeArtifact from 12.1.

Wood and foliage compiler buffers are contiguous numeric arrays. Scratch is owned
by one generation job/GenerationArena and discarded after artifact finalization.
No THREE.Vector3/material/geometry objects remain in semantic output.

======================================================================
PSEUDOCODE
======================================================================
GROW branch(node, depth):
    if depth>=limit or budget exhausted: return
    childCount := sample node child stream
    for childOrdinal stable:
        childSeed := node.seed.child("branch",ordinal)
        segment := derive direction/length/radius
        skeleton.append(segment)
        enqueue/grow child

COMPILE LOD:
    recipe := simplify skeleton based on lod
    foliage := cluster from same semantic crown
    return prototype artifact

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Different prototypes/species can build in parallel; a single skeleton build owns its arrays. No static mutable temporary state.

======================================================================
