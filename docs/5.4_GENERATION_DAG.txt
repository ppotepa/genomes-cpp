PUBLIC CONTRACTS
======================================================================
1. GenerationNode identity derives from generator ID + semantic node key + normalized input/dependency fingerprints, never schedule order.

2. DAG builder detects cycles before execution.

3. Node states: Planned, Waiting, Runnable, Running, Succeeded, Failed, Cancelled, SkippedDependencyFailure.

4. Independent nodes execute through JobSystem; result publication occurs only after generator success + validation hook.

DATA LAYOUT

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement graph builder with typed/artifact input references and stable NodeId.

STEP 2
    Topologically validate graph using Kahn/DFS with stable node ID ordering for diagnostics.

STEP 3
    Compile DAG into JobSystem dependency counters.

STEP 4
    On node failure, mark downstream skipped unless node policy declares optional dependency.

STEP 5
    Collect per-node timings/status/errors in GenerationReport.

STEP 6
    Test graph output equivalence at 1 and N workers and shuffled scheduler.

======================================================================
PSEUDOCODE
======================================================================
PLAN:
    for node:
        indegree[node] := dependency count
    stableQueue := nodes with indegree 0 sorted by NodeId
    pop/visit to detect cycle

EXECUTE NODE:
    if cancelled: Cancelled
    inputs := resolve immutable artifacts
    result := generator.generate(inputs, ctx)
    if failure: mark Failed; propagate
    validate result
    publish immutable artifact
    mark Succeeded
