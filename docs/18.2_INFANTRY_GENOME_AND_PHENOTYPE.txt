======================================================================
PUBLIC CONTRACTS
======================================================================
1. Genome stores requested normalized genes and seed/version; phenotype stores resolved metric anatomy. Resolution may constrain spatial relationships without mutating requested genome values.

2. Pipeline: seed -> base genome -> diversity scaling -> explicit overrides -> phenotype -> resolved anatomical relationships. Variation scale 0 is valid and maps genes toward midpoint behavior per SOURCE; NaN is invalid/default policy, never converted through truthiness.

3. Equipment/loadout/role cannot mutate biological genes. Side/faction cannot alter body/face identity unless explicit separate cosmetic policy.

4. BodyPhenotype contains metric skeletal landmarks/dimensions needed by rig, locomotion and fitting. FacePhenotype/FaceAnatomy exposes section(y), point(y,theta), frontZ and semantic landmarks for eyes/brows/mouth/jaw/nose/hairline.

5. Phenotype artifact is immutable and cacheable by genome/version/override hash.

6. Version domains are explicit. TARGET must not copy the SOURCE accident where
InfantryGenome.express() reports R.Config.GENERATOR_VERSION and that global value
is currently building-6.0.0. Native code defines independent versions for:
    InfantryGenome schema/generator
    Phenotype resolver
    Rig
    Appearance/surface generator
and records them in fixtures/artifacts. SOURCE docs identify the current
Infantry generator family as infantry-5.0.0; the mismatched runtime global is
recorded as legacy provenance, not adopted as native identity.

======================================================================
DATA LAYOUT
======================================================================
Store genes in explicit versioned struct or indexed schema with named accessors; do not use unordered string map in hot path. Phenotype uses doubles/floats in metres and normalized layout fields; cold requested/resolved diagnostics separate.

======================================================================
PSEUDOCODE
======================================================================
RESOLVE:
    base := generateGenome(seed, genomeVersion)
    varied := applyVariation(base, scale)
    requested := applyOverrides(varied, overrides)
    phenotype := solveBody(requested)
    face := solveFace(requested, phenotype)
    diagnostics := compareRequestedResolved(requested, phenotype, face)
    return immutable PhenotypeArtifact

VARIATION:
    require finite(scale)
    for gene:
        value := 0.5 + (base[gene]-0.5) * scale
        clamp to gene domain

CACHE KEY:
    H(generatorVersion, seed, scale, canonicalOverrides)
    // no equipment/loadout/camera fields

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Genome/phenotype resolution pure and parallel per unit/artifact. No shared mutable surface-builder state.

======================================================================
ERROR HANDLING
======================================================================
Nonfinite overrides/ranges return validation error with gene name. Resolver infeasible constraint returns typed error/diagnostic, not NaN geometry.

======================================================================
DETERMINISM RULES
======================================================================
SOURCE compatibility for infantry-5.0.0 uses the exact sequential legacy
streams and exact gene draw order from ALG-RNG-INFANTRY-GENOME32-001.

Canonical future native versions may use named SeedPath streams, but only after
a generator-version bump and parity report. Same artifact key is independent of
worker scheduling in either mode.

======================================================================
PERFORMANCE RULES
======================================================================
Phenotype generated on spawn/change only, not frame. Cache exact artifact keys. Batch independent units/jobs.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Selected SOURCE genome values may require exact parity; phenotype constraints use numeric/invariant parity. Version intentional visual changes.
