======================================================================
PUBLIC CONTRACTS
======================================================================
1. Transaction states: Building, ReadyToCommit, Committed, RolledBack, Failed, Cancelled. Commit is one-way and idempotence errors are explicit.

2. Candidate artifacts live in transaction-local store/handles until commit. Active ArtifactStore/World sees none of them before commit.

3. Commit acquires owning service mutation boundary once, validates dependency revision/generation, publishes artifacts in stable order, then swaps root references.

4. Rollback releases candidate references and temp files; cached immutable reusable artifacts may remain in global cache because they are content-addressed and valid.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement transaction-local publication list and validation summary.

STEP 2
    Capture base world/artifact revision at transaction begin.

STEP 3
    Before commit, verify active revision still matches or use explicit merge/retry policy; initial policy = Conflict error.

STEP 4
    Commit artifacts sorted by stable ArtifactId, then update root package pointer/revision last.

STEP 5
    Implement rollback on destructor only as safety; code must call explicit rollback/commit and destructor logs unclosed transaction in development.

STEP 6
    Test injected failure at every commit stage using fake store.

======================================================================
PSEUDOCODE
======================================================================
BEGIN:
    tx.baseRevision := world.revision

BUILD:
    tx.local.publish(candidate...)

PREPARE:
    if any validation error: Failed
    state := ReadyToCommit

COMMIT:
    lock worldCommitMutex
    if world.revision != baseRevision: return Conflict
    for artifact sorted by id:
        globalStore.publish(artifact)
    world.rootPackage := tx.newRoot
    world.revision += 1
    state := Committed

ROLLBACK:
    release local candidate ownership
    delete temp transaction files
    state := RolledBack
