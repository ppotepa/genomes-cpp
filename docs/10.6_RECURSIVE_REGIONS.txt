PUBLIC CONTRACTS
======================================================================
1. RegionNode has stable RegionNodeId, parent, level, polygon, seed path, development/accessibility parameters and terminal reason.

2. Subdivision uses road corridor/axis/weighted geometric split with hard min area/aspect/simple-polygon constraints. Children exactly cover parent within numeric tolerance minus explicit ROW exclusions if policy says so.

3. Max depth/node budget explicit. Failed split leaves valid leaf with trace reason, not invalid geometry.

4. Stable child IDs derive from parent ID + split semantic ordinal, not vector insertion order.

======================================================================

Graphs use contiguous node/edge arrays with stable IDs and adjacency ranges; fields are grid/raster artifacts; polygons use engine geometry types.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define RegionSubdivisionSpec min/max area, depth, morphology weighting.

STEP 2
    Generate candidate split axes from nearby major road directions, principal axis, center/gateway vectors and deterministic jitter.

STEP 3
    Clip parent into child polygons using robust half-plane/corridor operation; validate both.

STEP 4
    Score area balance, access/frontage opportunity, aspect, morphology alignment; choose deterministic best.

STEP 5
    Recurse/queue until leaf criteria/budget.

STEP 6
    Validate coverage/overlap and export debug trace polygons.

======================================================================
PSEUDOCODE
======================================================================
SPLIT NODE:
    if terminal criteria: leaf
    candidates := stable candidate axes
    best := none
    for c:
        A,B := split(parent.polygon,c)
        if !valid(A) or !valid(B): reject
        score := weighted objectives
        choose score then stable candidate ID
    if none: leaf(reason=NoValidSplit)
    else create children IDs 0/1 and enqueue

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Each generation stage reads immutable prior artifacts and writes a candidate output; independent regions/blocks/parcels use jobs with stable IDs and stable merge.

======================================================================
ERROR HANDLING
======================================================================
Invalid candidates are rejected through typed result/ValidationReport; bounded fallback strategies are explicit and traced.

======================================================================
DETERMINISM RULES
======================================================================
Stable seed paths, node/edge IDs and deterministic tie-breakers define output; hash-map/job iteration never does.

======================================================================
PERFORMANCE RULES
======================================================================
Use spatial indexes/fields rather than global scans; batch expensive routing/placement and benchmark large city profiles.
