======================================================================
PUBLIC CONTRACTS
======================================================================
1. Polygon2 stores one outer ring initially; holes are explicit PolygonWithHoles type, never encoded by magic winding in the base type.

2. Validation distinguishes TooFewVertices, DegenerateArea, SelfIntersection, DuplicateEdge, NonFinite.

3. pointInPolygon returns Outside/Inside/Boundary.

4. Offset API returns zero/one/multiple polygons because concave offsets can split/collapse; callers may not assume one polygon.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement ring normalization: remove exact/within-domain duplicate consecutive points only under caller tolerance, preserve semantic coordinates.

STEP 2
    Implement signed area, perimeter, centroid with explicit degenerate failure.

STEP 3
    Implement O(n^2) validation baseline using robust segment predicates; acceleration can follow after profiling.

STEP 4
    Implement point classification and half-plane clipping.

STEP 5
    Choose and pin triangulation/offset implementation: prefer proven library for robust concave offset/triangulation; wrap behind Genomes API and record license.

STEP 6
    Add property/fuzz tests for translated/reversed polygons, concavity and collapse.

======================================================================
PSEUDOCODE
======================================================================
VALIDATE:
    if n < 3: fail TooFew
    if any !finite: fail NonFinite
    for non-adjacent edge pairs:
        if intersection is Proper/Overlap: fail SelfIntersection
    if abs(signedArea) < areaTolerance: fail Degenerate
    return Valid

OFFSET:
    validate input
    backendResult := offsetBackend(ring, distance)
    normalize every returned ring
    validate every returned polygon
    return vector<Polygon2>
