======================================================================
PUBLIC CONTRACTS
======================================================================
1. PlantGenome is compact semantic DNA: species ID, root seed, stable traits (height/girth/branching/crown/asymmetry/leaf density/color/etc.) and optional runtime damage/season state separated where identity vs transient differs.

2. PlantPrototypeArtifact describes branch skeleton/primitive recipes, foliage clusters, collision/interaction bounds and semantic LOD recipe set. LODs derive from same genome/skeleton identity.

3. Species catalog is data/versioned and no renderer material objects live in it.

4. PrototypeKey includes species/genome generator version + stable genome + age/season parameters that actually affect geometry.

PSEUDOCODE
======================================================================
CREATE GENOME:
    rng := seed.child("plant-genome", plantId)
    for trait in species.traits stable order:
        genome[trait] := sample species distribution using trait child stream
    return genome

PROTOTYPE:
    skeleton := growBranchSkeleton(genome, age)
    crown := deriveFoliageClusters(skeleton, genome)
    for lod:
        recipe[lod] := simplifySameIdentity(skeleton,crown,lodPolicy)

THREADING / OWNERSHIP RULES
======================================================================

ERROR HANDLING

DETERMINISM RULES
======================================================================
Trait child streams isolate changes; adding a new trait does not shift unrelated trait RNG if semantic child labels used.

======================================================================
PERFORMANCE RULES
======================================================================
Prototype sharing/caching by exact semantic key. Many world instances reference prototypes rather than unique mesh geometry.
