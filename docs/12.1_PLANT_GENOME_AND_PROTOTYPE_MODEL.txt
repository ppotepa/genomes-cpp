======================================================================
PUBLIC CONTRACTS
======================================================================
1. PlantGenome is compact semantic DNA: species ID, root seed and stable genes:
    stature
    spread
    branching
    crookedness
    foliage
    leafSize
    fruiting
    girth
    damage

Age and season are NOT biological genome genes; they are separate prototype/
presentation state inputs. The damage gene is part of TARGET genome identity.
Each gene derives from a named SeedPath so schema extension does not reroll
unrelated genes.

2. PlantPrototypeArtifact describes branch skeleton/primitive recipes, foliage clusters, collision/interaction bounds and semantic LOD recipe set. LODs derive from same genome/skeleton identity.

3. Species catalog is data/versioned and no renderer material objects live in it.

4. PrototypeKey includes the CORRECT vegetation generator/version domain plus
stable genome and geometry-affecting age/season/detail inputs.

Vegetation schema/generator identity is explicit and independent from building,
world and renderer versions.

======================================================================
DATA LAYOUT
======================================================================
Species catalog:
    contiguous/versioned PlantSpeciesDefinition records keyed by stable SpeciesId.

PlantGenome:
    version
    SpeciesId
    uint32/64 seed
    compact fixed-order gene values
    identity hash

PlantPrototypeArtifact:
    BranchNode/BranchSegment contiguous arrays
    foliage cluster arrays
    prototype bounds/collision metadata
    LOD recipe descriptors referencing the same semantic skeleton

Age/season/runtime damage that affects geometry is represented explicitly in
prototype/artifact keys; transient display-only state is not folded into
biological genome identity.

======================================================================
PSEUDOCODE
======================================================================
CREATE GENOME:
    genes := SeedTree(seed).child("plant/genome")
    genome.stature     := .25 + genes.value("stature")*.5
    genome.spread      := .25 + genes.value("spread")*.5
    genome.branching   := .25 + genes.value("branching")*.5
    genome.crookedness := .25 + genes.value("crookedness")*.5
    genome.foliage     := .25 + genes.value("foliage")*.5
    genome.leafSize    := .25 + genes.value("leafSize")*.5
    genome.fruiting    := .25 + genes.value("fruiting")*.5
    genome.girth       := overrideOr(.5)
    genome.damage      := overrideOr(0)

PROTOTYPE:
    skeleton := growBranchSkeleton(genome, age)
    crown := deriveFoliageClusters(skeleton, genome)
    for lod:
        recipe[lod] := simplifySameIdentity(skeleton,crown,lodPolicy)

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Genomes/prototypes immutable. Each prototype build owns scratch. Species catalog immutable after bootstrap.

======================================================================
ERROR HANDLING
======================================================================
Invalid procedural candidates return typed validation failures; missing optional visual detail degrades by explicit representation policy, not silent corruption.

======================================================================
DETERMINISM RULES
======================================================================
Trait child streams isolate changes; adding a new trait does not shift unrelated trait RNG if semantic child labels used.

======================================================================
PERFORMANCE RULES
======================================================================
Prototype sharing/caching by exact semantic key. Many world instances reference prototypes rather than unique mesh geometry.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET plant schema and invariants are authoritative. Reference catalogs may
inform species ranges but cannot select generation behavior.
