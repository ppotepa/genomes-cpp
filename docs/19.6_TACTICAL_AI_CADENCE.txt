======================================================================
PUBLIC CONTRACTS
======================================================================
1. AI model operates on immutable Observation and returns Intent; it never mutates unit/world/weapon directly.

2. Perception Observation contains self state, sorted visible enemies, remembered target/last known position, task context and tick/time derived from SimulationTick.

3. Cadence uses integer tick periods/stable phase staggering, not per-agent floating accumulator. SOURCE 0.2s at 60Hz => compatibility period 12 ticks.

4. Target memory compatibility duration 2.5s => tick count profile. Memory updates when visible; expires deterministically by SimulationTick.

5. Model exceptions/failures become diagnostic and switch entity to passive safe model/intent without corrupting system. Native C++ uses Result/error boundary, not exception as normal path.

======================================================================
DATA LAYOUT
======================================================================
Observation temporary batch/arena data; AIState component contains modelId, target memory, last observation tick, cadence tier. Intent compact command data.

PSEUDOCODE
======================================================================
DUE AI:
    if cadence.due(entity,tick):
        observation := buildObservation(...)
        intent := model.update(observation, elapsedTicks)
        aiState.lastObservationTick := tick
        intents.push(entity,intent)

MEMORY:
    if visible current target:
        memory := {id,pos,seenTick=tick}
    else if tick-memory.seenTick <= memoryTicks:
        target := lastKnown(memory)
    else:
        clear memory

TARGET SWITCH:
    nearest := visible[0]
    if no chosen: choose nearest
    else if nearest.distance < chosen.distance * 0.85:
        choose nearest

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Observation/model updates parallel entity batches; model state owned by entity chunk. Intents stable-merged. Registry immutable.

======================================================================
ERROR HANDLING
======================================================================
Unknown model -> passive + diagnostic. Model error -> passive fallback and trigger-off intent. No dangling callback/exception crossing jobs.

======================================================================
DETERMINISM RULES
======================================================================
Cadence phase/id/tick stable. Visible list sorted. Memory and target switching deterministic.

======================================================================
PERFORMANCE RULES
======================================================================
AI updates only due entities. Perception broadphase/LOS shared results. No N². Track updates/tick, candidates, LOS, model time.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Preserve simple-combat behavior as baseline, not limitation. More capable models can be added without changing engine.
