bounding expensive rigid bodies: HERO dynamic bodies -> CHEAP ballistic/gravity

======================================================================
PUBLIC CONTRACTS
======================================================================
1. Debris representation tier is separate from semantic detached material identity. DebrisRecord stores stable DebrisId, source StructuralElementId(s), material-volume mix, transform/velocities, semantic geometry/artifact refs and tier.

2. Hero tier uses Jolt dynamic body for important/large/near/interactive chunks under explicit retained and awake budgets. Sleeping hero remains dynamic and can wake/fall if support changes.

3. Cheap tier stores simplified position/orientation/linear/angular velocity, bounds, material mix and optional retained visual mesh handle; integrates gravity/ground/rubble collision approximately without full body contacts.

4. Baked tier transfers material volume into RubbleField. If hero budget full -> cheap; if cheap budget full/unrepresentable -> direct baked deposit. No material disappears because representation budget is exhausted.

5. Bake order: deposit all settling candidates -> rebuild/commit affected rubble collision/field -> only then destroy old hero/cheap representations.

======================================================================
DATA LAYOUT
======================================================================
Hero table small bounded handles; Cheap SoA arrays for position/velocity/orientation/volume/material mix; Baked volume lives in RubbleField. RepresentationAccounting aggregates hero+cheap+baked by material/source.

======================================================================
PSEUDOCODE
======================================================================
SPAWN DETACHED:
    if qualifiesHero and heroBudget.available:
        if physicsShapeBuild succeeds:
            create hero
            return
    if cheapBudget.available:
        create cheap record
        return
    rubble.deposit(materialVolumes, position)
    mark baked

BAKE BATCH:
    candidates := settled hero + cheap
    transaction:
        for d in candidates:
            rubble.deposit(d.materialVolumes, d.position, spread)
        rubble.flushDirtySemanticTiles()
        collisionUpdate := compile dirty rubble
        commit collision/field
        for d in candidates:
            remove hero body / cheap record
            d.tier := Baked
    assert accounting conserved

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Hero physics state read after physics step. Cheap arrays integrate in parallel batches, generating settle commands. Rubble deposits commit under tile ownership. Tier transitions occur at deterministic commit points.

======================================================================
ERROR HANDLING
======================================================================
Unrepresentable physics hull, budget pressure or collider failure triggers explicit fallback tier and metric; never silent deletion. If rubble tile/collision compile fails, keep prior debris tier until safe fallback field representation exists.

======================================================================
DETERMINISM RULES
======================================================================
Tier policy may depend on semantic importance/distance profile but must not depend on particle-quality settings. Conservation and DebrisId stable; visual priority may be camera-dependent without affecting semantic material.

======================================================================
PERFORMANCE RULES
======================================================================
Expensive active bodies naturally decay into cheap/baked forms. Cheap SoA integration and batch bakes; no physics body per tiny fragment.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Use latest SOURCE rubble-field semantics as authoritative over older building-damage docs that deleted overflow debris.
