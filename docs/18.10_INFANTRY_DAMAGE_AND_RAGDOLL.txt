======================================================================
PUBLIC CONTRACTS
======================================================================
1. InfantryDamageModel maps semantic anatomical regions/armor/equipment protection into generic destruction/ballistics hit target interfaces. It does not expose skin triangles as authoritative anatomy.

2. Hit volumes are updated from authoritative/current animation pose snapshot in bounded batches and registered in dynamic spatial query index once per simulation phase.

3. RagdollSchema is immutable phenotype/skeleton-derived body/constraint data. Active physics bodies are created lazily only on ragdoll/interaction need.

4. Transition to ragdoll transfers root/limb world transforms and estimated linear/angular velocities from pose snapshots into PhysicsCommandBuffer at one deterministic tick.

5. Ragdoll physics output affects entity/presentation through controlled state synchronization; renderer does not own bodies.

======================================================================
DATA LAYOUT
======================================================================
HitVolume array per anatomy region with SemanticPartId, shape recipe, transform, material/protection refs. RagdollSchema compact body/constraint arrays. Runtime has handles only when active.

======================================================================
PSEUDOCODE
======================================================================
UPDATE HIT VOLUMES:
    parallel_for infantry chunks:
        pose := currentAuthoritativePose
        for region in fixed regions:
            volume.transform := pose * region.bindOffset
    barrier
    dynamicSpatialIndex.batchUpdate(all changed volumes)

ENTER RAGDOLL:
    schema := ragdollCache.getOrBuild(phenotype,rig)
    for body in schema:
        world := poseWorld(body.bone)
        linear := (world.pos - previousWorld.pos)/fixedDt
        angular := quaternionDeltaToOmega(previous,current,fixedDt)
        commands.createDynamic(body.shape, world, linear, angular)
    commands.createConstraints(schema)
    physics.flush
    entity.state := RagdollActive

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Hit transform computation parallel disjoint; spatial index updates batched. Ragdoll creation committed through physics sync phase.

======================================================================
ERROR HANDLING
======================================================================
Missing pose/schema/protection mapping is validation error. Failed ragdoll body creation leaves non-ragdoll dead/disabled presentation fallback and diagnostics; no half-owned handles.

======================================================================
DETERMINISM RULES
======================================================================
Transition tick and body creation command order stable by entity/bone ID. Physics trajectory parity is behavioral/invariant, not necessarily bitwise.

======================================================================
PERFORMANCE RULES
======================================================================
No active ragdoll solver for ordinary living army. Hit volumes compact/batched. Limit active ragdolls by world policy with safe sleep/baked corpse representation later if needed.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET hit-volume semantics and lazy ragdoll activation define behavior; Jolt is
used only through the physics abstraction.
