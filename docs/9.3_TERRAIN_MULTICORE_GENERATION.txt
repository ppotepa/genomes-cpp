======================================================================
PUBLIC CONTRACTS
======================================================================
1. Partition by stable row/tile ranges; each job writes exclusive output span. Border-dependent normals run after heights barrier or use ghost rows with clear dependency.

2. Cancellation checked at bounded row/tile intervals. Cancelled candidate is never published.

3. Stage DAG: positions/height -> normals/slope -> material field -> tile bounds/statistics; independent post stages may parallelize.

======================================================================
DATA LAYOUT
======================================================================
Terrain work is partitioned into deterministic tile/row ranges.

Per job:
    TerrainTileRange {x0,z0,x1,z1}
    read-only generator parameters
    JobScratchArena temporary noise/derivative data
    exclusive output span for primary samples

Neighbor-dependent derived passes use explicit halo/input spans and write a
separate destination field; no two jobs write the same output element.

Final HeightFieldArtifact arrays remain contiguous row-major. Job descriptors,
temporary halos and reduction buffers are transient and are not serialized.

======================================================================
IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement parallel height row generation using parallelFor fixed batch identity.

STEP 2
    Barrier before normal computation; normal jobs read immutable complete height field and write normal/slope arrays.

STEP 3
    Compute min/max/tile bounds using per-batch local reductions then stable reduction.

STEP 4
    Add cancellation tests and no-partial-publish transaction integration.

STEP 5
    Benchmark serial vs 1/2/4/8/16 workers at multiple resolutions and report memory bandwidth saturation.

======================================================================
PSEUDOCODE
======================================================================
HEIGHT:
    parallelFor rows:
        for x: heights[index]=sampleNoise(seed,x,z)
    wait

NORMAL:
    parallelFor rows:
        read neighbor heights
        write normals/slope

REDUCE:
    localStats[batch] := min/max
    final := reduce localStats in batchIndex order

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Exclusive writes per batch; no atomics per sample. Reduction local then stable merge.

======================================================================
ERROR HANDLING
======================================================================
Invalid procedural candidates return ValidationReport/Result. Active world is changed only through generation transaction commit.

======================================================================
DETERMINISM RULES
======================================================================
Byte/numeric output equals serial within defined float policy regardless worker count.

======================================================================
PERFORMANCE RULES
======================================================================
Choose row grain large enough to amortize scheduling; report speedup and memory bandwidth plateau.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET uses real native parallel jobs with bounded cancellation points and
schedule-independent output.
