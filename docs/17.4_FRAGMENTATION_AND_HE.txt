======================================================================
PUBLIC CONTRACTS
======================================================================
1. FuzeProfile v1 supports Contact {armed}; future delay/proximity/programmed are separate modes and not simulated implicitly. Contact candidate must be validated against actual surface point before fuze triggers.

2. HE projectile performs bounded nose-crush kinetic contact up to profile distance (SOURCE compatibility quarter diameter where configured) before explosive detonation state; kinetic and explosive ledger terms remain separate.

3. FragmentationProfile defines fragmentCount, bodyMassFraction, explosiveEnergyFraction, massSpread/angular distribution and body translation inheritance. Fragments become child ProjectileStates with parentTrace/Shot relation.

4. Fragment generation uses opposite direction pairs for radial components so pair radial momentum cancels; translation/expansion cross-term/energy allocation is accounted. Capacity truncation omits complete pairs and moves missing energy/mass to unrepresented categories rather than boosting survivors.

5. BlastSolver produces spatial BlastDamageCommands over nearby solids/rubble with attenuation/occlusion policy versioned. Blast can create holes/fractures/support damage and excavate RubbleField; it does not route all energy through tiny fragment crater shortcut.

======================================================================
DATA LAYOUT
======================================================================
HE event uses immutable profile + transient BlastEvent. Fragment array allocated from projectile pool/batch with stable child IDs. Blast candidate list from WorldQuery spatial broadphase; commands grouped per target.

PSEUDOCODE
======================================================================
DETONATE:
    surface := verify actual contact
    noseResult := apply bounded crush contact
    explosive := profile.explosiveEnergy
    Efrag := explosive * fragFraction
    Eblast := explosive * blastFraction
    Eunrepresented := explosive - Efrag - Eblast

    pairs := floor(fragmentCount/2)
    allowedPairs := min(pairs, projectileCapacity/2)

    for pairOrdinal in [0,allowedPairs):
        dir := sample hemisphere/sphere child seed
        for sign in [-1,+1]:
            mass := paired/sample mass
            radialSpeed := solve allocated pair expansion energy
            v := parent.velocity + sign*dir*radialSpeed
            create child projectile stable ID(parent,pair,sign)

    omitted complete pairs -> ledger.unrepresentedEnergy/mass

BLAST:
    candidates := spatial query radius
    compute falloff/occlusion
    emit grouped BlastDamageCommands
    rubble.excavate/re-eject bounded
    commit damage batch then rebuild logical index once

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Detonations in projectile jobs emit fragment spawn/blast commands. Fragment creation and blast damage commit use stable parent/shot/ordinal ordering. Different targets can process grouped damage jobs.

======================================================================
ERROR HANDLING
======================================================================
Invalid profile energy fractions/mass fractions fail catalog validation. Projectile-capacity pressure never rescales survivor fragments to consume omitted budget. Fuze unsupported mode returns Unsupported, not fake contact behavior.

======================================================================
DETERMINISM RULES
======================================================================
Fragment seeds/IDs from parent + pair ordinal/sign. Capacity choice based on stable pair order. Blast candidate order stable for damage commits.

======================================================================
PERFORMANCE RULES
======================================================================
Broadphase radius query, grouped target damage, bounded fragments and effects. Fragment projectiles share batching/SpatialTrace path.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Preserve SOURCE HE contracts and ledger categories. Visual flash/dust pools are Stage20 presentation, not semantic fragmentation.
