======================================================================
PUBLIC CONTRACTS
======================================================================
1. SharedPath key includes destination/corridor/capability/nav revision and optional formation/task route ID. Agents hold handle/reference plus local offset/progress, not copy full path.

2. FlowField is local grid over tactical area with integration cost + direction; CPU canonical implementation uses Dijkstra/wavefront from destination over nonnegative costs.

3. GPU backend is optional later/Stage21; CPU flow field always available.

4. Individual local avoidance/door decisions may diverge from shared path without invalidating high-level route.

======================================================================

Public nav handles/paths are Genomes types. Recast/Detour pointers and poly refs remain backend-private mappings.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement SharedPathCache with reference counts/TTL/revision invalidation.

STEP 2
    Build path once per group request then agents attach and project to nearest corridor progress.

STEP 3
    Implement local FlowField grid generation from movement cost/obstacle field and destination cells.

STEP 4
    Derive direction from lowest integration neighbor/gradient with stable tie order.

STEP 5
    Define replan triggers: destination revision, corridor invalidation, agent separated beyond threshold—not every frame.

STEP 6
    Benchmark 1/10/100/1000 agents same destination vs independent path requests.

======================================================================
PSEUDOCODE
======================================================================
SHARED:
    key := {goal,corridorId,profile,navRevision}
    path := cache.getOrBuild(key)
    agent.sharedPath := handle(path)

FLOW:
    cost[goal]=0
    priorityQueue.push(goal)
    while queue:
        c := popMin
        for n stable neighbors:
            new := cost[c]+moveCost(n)
            if new < cost[n]:
                cost[n]=new; push n
    for cell:
        direction := vector to valid neighbor with min cost
