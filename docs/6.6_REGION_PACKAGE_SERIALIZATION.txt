======================================================================
PUBLIC CONTRACTS
======================================================================
1. RegionPackage contains header/provenance, RegionId/coord/bounds, artifact references or embedded selected semantic artifacts, static record pages, compiler recipe refs and dependency fingerprints.

2. Do not serialize live Diligent/Jolt/Recast handles. Render/physics/nav runtime representations are rebuilt from recipes/artifacts or stored in separately versioned backend cache blobs.

3. Package reader validates magic/version/size/content hash and hard resource limits before allocations.

4. Package write is deterministic canonical order and atomic at file level.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.

======================================================================
PSEUDOCODE
======================================================================
WRITE:
    sections := buildSectionsInStableTypeOrder()
    header := {magic,version,regionId,sectionCount}
    reserve section table
    for section:
        align output
        write canonical bytes
        record offset,length,hash
    finalize table
    atomic write

READ:
    read header
    validate version/limits
    read section descriptors
    for descriptor:
        validate offset+length within file
        verify hash
    expose immutable package view
