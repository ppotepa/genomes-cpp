GOAL
======================================================================
Create the native Infantry domain module boundary so all infantry-specific anatomy, genome, equipment, animation, damage and presentation depend on generic engine services while the engine remains compilable without Infantry.

======================================================================
PUBLIC CONTRACTS
======================================================================
1. modules/infantry may depend on engine/foundation, simulation, world, render contracts, physics abstraction, navigation and other domain modules explicitly named by chapter. No engine target may link modules/infantry.

2. Generic entity state is composed from engine ECS components; Infantry adds domain components/tables keyed by EntityId.

3. InfantryModule registers systems/components/services during app composition, not through hidden static globals.

4. Build option GENOMES_ENABLE_INFANTRY may disable the entire module; genomes_headless/proc_viewer core procedural world must still compile and run without it.

5. Cross-domain interaction uses IDs/events/contracts: Combat/Weapons may reference Infantry capabilities through narrow interfaces, not include renderer/anatomy internals.

======================================================================
DATA LAYOUT
======================================================================
InfantryModule contains registration descriptors and domain component IDs only. No singleton Unit object graph. EntityId is engine-owned; Infantry-specific cold state lives in module storage.

PSEUDOCODE
======================================================================
COMPOSE APP:
    engine := createEngineServices()
    modules := ModuleRegistry(engine)
    if config.enableInfantry:
        modules.register(InfantryModule)

INFANTRY REGISTRATION:
    register component InfantryIdentity
    register placeholder domain systems only when implemented
    no static global initialization

BUILD WITHOUT INFANTRY:
    configure -DGENOMES_ENABLE_INFANTRY=OFF
    build genomes_headless genomes_proc_viewer
    run procedural/world smoke tests

THREADING / OWNERSHIP RULES
======================================================================
