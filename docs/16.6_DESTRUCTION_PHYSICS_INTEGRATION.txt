======================================================================
PUBLIC CONTRACTS
======================================================================
1. Destruction semantic commit decides Detach/Demote/Bake/Remove. Physics bridge converts those decisions into PhysicsCommandBuffer operations and returns handles/results; physics callbacks never decide semantic damage.

2. Hero debris collision shape uses convex/compound recipes; dynamic triangle mesh is forbidden unless Jolt specifically supports chosen mode and benchmark/robustness proves it. Shape compile failure triggers cheap/baked fallback.

3. Impulse from ImpactResult is applied exactly once to target/debris through physics command path. Structural damage deposition does not add heuristic duplicate impulse.

4. Semantic debris transform can be synchronized from PhysicsSnapshot after step; mapping is DebrisId <-> PhysicsBodyHandle, no raw backend pointer.

5. Settled bake transaction follows 16.4 ordering. Rubble collision swap is static-region/local body update; only after replacement field/collision valid are hero bodies removed.

======================================================================
PSEUDOCODE
======================================================================
DETACH COMMIT:
    debris := semantic create
    shape := compileHeroShape(debris.geometry)
    if hero policy + shape success:
        physicsCommands.createDynamic(debrisId,shape,transform,mass)
        physicsCommands.applyImpulse(debrisId, impactImpulseOnce)
    else:
        debrisLifecycle.spawnCheapOrBake(...)

AFTER PHYSICS:
    snapshot := changed hero bodies
    for body:
        update semantic debris kinematics
        if sleeping/settle criteria:
            settleCommands.push(debrisId)

BAKE:
    semantic/rubble transaction deposit+collision replacement
    after safe commit -> physics destroy hero

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
All Jolt mutation follows PhysicsWorld command phases. Destruction jobs never call BodyInterface directly. Bridge owns mapping table on physics/destruction commit thread.

======================================================================
ERROR HANDLING
======================================================================
Shape build/body creation failure increments diagnostic and falls back representation. Mapping inconsistency is assertion in development plus safe semantic fallback in release.

======================================================================
DETERMINISM RULES
======================================================================
Physics trajectories may not be bit-identical across platforms; semantic tier transitions use bounded thresholds/tick counts and source IDs. Material conservation remains deterministic independent of exact body path within tolerance.

======================================================================
PERFORMANCE RULES
======================================================================
Bound hero body counts, pooled shape recipes, batch create/remove, cheap/baked decay. Benchmark collapse peak/p95 and active body decay.
