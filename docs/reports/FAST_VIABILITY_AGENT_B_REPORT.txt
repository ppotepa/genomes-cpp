FAST VIABILITY — AGENT B PROCEDURAL WORLD
==========================================

viability: runnable (CPU/headless)

The deterministic WorldScenario now commits one backend-neutral artifact:
WorldPlan (terrain patch, hydrology, roads/city parcels, building sites and
vegetation), a matching terrain HeightField/TerrainMesh, and a canonical empty
entity WorldSave package. WorldStreamer preloads one adjacent region through
the same request/seed path while the first artifact remains immediately usable.
ProcViewer and the optional headless --world path print the semantic counts,
terrain mesh size, save package size and streaming residency.

Build:
  cmake --preset dev-debug -DGENOMES_BUILD_TESTS=ON -DGENOMES_BUILD_BENCHMARKS=OFF
  cmake --build build/dev-debug --target genomes_headless genomes_proc_viewer

Run:
  build/dev-debug/apps/headless/genomes_headless.exe --world
  build/dev-debug/apps/proc_viewer/genomes_proc_viewer.exe
