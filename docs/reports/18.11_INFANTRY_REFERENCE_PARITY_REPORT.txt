GENOMES NATIVE VALIDATION NOTE
=============================

STATUS:
    Exact JS-to-C++ output parity is not required and is not a release gate.

REFERENCE PURPOSE:
    The JavaScript mockup and pinned GNIF artifacts are concept/design evidence
    for character, equipment, animation-state, and visual concepts. Provenance
    and fixture-format integrity remain useful; JavaScript-generated values do
    not define native C++ outputs.

NATIVE ACCEPTANCE:
    Use focused C++ tests for explicitly adopted domain requirements and native
    invariants. The general native suite must not require full-buffer comparison
    against JS. GNIF reader success means structural integrity only.

OPTIONAL DIAGNOSTIC:
    tests/native/infantry_reference_parity_tests.cpp is compiled only when
    GENOMES_BUILD_INFANTRY_REFERENCE_COMPARISON=ON. Its CTest name is
    infantry.reference_comparison; it is diagnostic and non-gating.
