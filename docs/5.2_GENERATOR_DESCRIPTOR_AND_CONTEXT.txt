======================================================================
PUBLIC CONTRACTS
======================================================================
1. GeneratorDescriptor has stable GeneratorId/string name, semantic version, input/output type IDs, deterministic flag, execution policy CPU/GPU-capable, cache policy.

2. GenerationContext is per request/job: SeedPath, JobSystem&, ScratchContext&, CancelToken, ArtifactReader&, Diagnostics context, optional ComputeService interface pointer nullable until Stage 8.

3. Registry is immutable after bootstrap for runtime fast reads; duplicate stable ID/name fails startup.

4. Generator implementation is callable/service object injected into registry; no static global discovery magic.

======================================================================
DATA LAYOUT
======================================================================
Prefer compact value types, contiguous hot data and explicit ownership.

IMPLEMENTATION STEPS

STEP 2
    Define descriptor validation: nonempty name, nonzero version/type IDs, deterministic/cache compatibility.

STEP 3

STEP 4

STEP 5

======================================================================
PSEUDOCODE
======================================================================
BOOT:
    builder.add(TerrainGenerator.descriptor, instance)
    builder.add(BuildingGenerator.descriptor, instance)
    registry := builder.freeze()

RUN:
    entry := registry.find(id)
    ctx := GenerationContext(seedPath, jobs, scratch, cancel, artifacts, diagnostics)
    return entry.generator.generate(input, ctx)
