======================================================================
PUBLIC CONTRACTS
======================================================================
1. AI tick graph: relevance/cadence due selection -> spatial broadphase -> LOS batches -> observation/memory -> squad shared updates/signals as dependencies -> model update -> deterministic intent commit.

2. Jobs are batches by spatial region/chunk/squad, never permanent subsystem threads and never one tiny job per agent.

3. Task dependencies use JobSystem handles/counters; no worker blocks on OS condition while runnable work exists.

4. All intermediate arrays allocated from frame/job scratch and published only after barriers.

5. 1-worker semantic output is reference; N-worker output identical for deterministic AI state/intents.

======================================================================
DATA LAYOUT
======================================================================
Per-tick AIPipelineScratch owns due entity arrays, candidate ranges, LOS request/result arrays, observations, local intent buffers. Long-lived AIState/SquadState stay ECS/domain storage.

PSEUDOCODE
======================================================================
PIPELINE:
    due := cadence.collectDue(tick)

    broadphaseJobs := parallel_for(batch(due)):
        candidates[batch] := spatialCandidates(...)

    losBuild := after(broadphaseJobs):
        flatten candidate pairs -> LOSRequests + offsets

    losJobs := parallel_for(batch(LOSRequests)):
        LOSResults := world.batchLOS(...)

    obsJobs := after(losJobs, squadSnapshotReady):
        parallel_for(batch(due)):
            observations := build(...)

    modelJobs := after(obsJobs):
        parallel_for(batch(observations)):
            localIntents.push(model.update(...))

    wait modelJobs
    intents := stableMerge(localIntents, entityId,sequence)
    combat.commit(intents)

THREADING / OWNERSHIP RULES
======================================================================
Exactly the JobSystem pattern above; no AI-owned worker pool. Scratch job-local/phase-owned. ECS writes confined to owned chunks or commit.
