======================================================================
PUBLIC CONTRACTS
======================================================================
1. Appearance generation consumes immutable phenotype+skeleton+appearance genes/options and produces backend-neutral MeshData/skin/morph artifacts. No live renderer objects.

2. Skin has real topological eye/mouth openings and connected neck/head transition; hidden caps/shader masking may not replace topology where SOURCE contract requires opening.

3. Each skinned vertex has <=4 normalized influences with stable BoneIndex values. Morph targets store relative deltas/normals and are generated once.

4. Hair genome identity is immutable; headgear clipping later produces presentation/gear visibility mask without mutating hair style.

5. Appearance cache key includes all geometry-affecting phenotype/generator/detail inputs and excludes runtime pose/emotion/equipment unless geometry actually depends on equipment layer compile.

======================================================================
DATA LAYOUT
======================================================================
AppearanceArtifact contains body MeshData, optional hair/detail submeshes, skinIndices/weights, morph target arrays, material region IDs, bounds and version/hash. Keep source builder scratch in GenerationArena.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement the generic surface ring/profile builder using local
    GenerationContext scratch and no shared mutable state.

STEP 2
    Generate torso/limbs/neck/head from phenotype profiles; preserve seam/index continuity where required.

STEP 3
    Generate eye/mouth openings and surrounding rings/interior surfaces.

STEP 4
    Generate face details/eyes/nose/ears/brows from final FacePhenotype landmarks.

STEP 5
    Generate hair by seven style families; bald emits no mesh; seeded variation comes from appearance stream.

STEP 6
    Assign <=4 normalized skin influences and validate sum/indices.

STEP 7
    Generate the four TARGET morphs with relative deltas/normals:
    eyelidsClose, eyelidsArc, neckFlex and handsRelax. Finger articulation is
    skeletal; handsRelax supplies compatible soft-tissue deformation only.

STEP 8
    Implement exact-key AppearanceArtifact cache with ref/lifetime policy from Stage 5/assets.

STEP 9
    Benchmark generation and cache hit for many unique/duplicate phenotypes.

PSEUDOCODE
======================================================================
BUILD APPEARANCE:
    key := hash(generatorVersion, phenotypeHash, appearanceGenes, detailLevel)
    if cache.contains(key):
        return cache.acquire(key)

    ctx := GenerationArena scoped
    body := buildBodySurface(ctx, phenotype)
    face := buildFaceOpeningsAndDetails(ctx, phenotype.face)
    skin := assignSkinWeights(body+face, skeleton)
    morphs := buildMorphTargets(...)
    hair := buildHair(...)
    validateMeshSkinMorphs(...)
    artifact := finalize immutable arrays
    cache.commit(key, artifact)
    return artifact

WEIGHTS:
    select semantic candidate bones
    retain top <=4 positive weights
    normalize sum to 1
    require finite

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Each build owns GenerationContext/scratch. Cache commit synchronized by artifact key with duplicate-build race policy (first wins/discard duplicate or shared future). No shared mutable builder globals.

======================================================================
ERROR HANDLING
======================================================================
Invalid topology/nonfinite vertex/weight/morph mismatch fails artifact generation with trace. Cache failure does not return partial geometry.

======================================================================
DETERMINISM RULES
======================================================================
Vertex/index emission order stable for same generator version. Hair/appearance random streams independent of job order and equipment.

======================================================================
PERFORMANCE RULES
======================================================================
No per-frame generation. Cache exact hits. Final arrays tightly packed. Avoid one object per vertex. Benchmark memory retained and build peak.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
TARGET topology, bounds, skinning and morph invariants are authoritative.
Selected SOURCE images may inform manual review but never define mesh layout.
