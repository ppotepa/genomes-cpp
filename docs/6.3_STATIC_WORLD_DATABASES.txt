======================================================================
PUBLIC CONTRACTS
======================================================================
1. StaticWorldDatabase owns per-region records/pages and stable IDs; domain artifacts remain referenced by ArtifactId.

2. BuildingRecord stores ID, transform, plan artifact ref, compact state flags and representation handles only when resident; detailed semantic plan is artifact data.

3. Vegetation InstancePage groups same prototype/material/LOD family in SoA arrays; no ECS entity per passive plant.

4. Road/parcel databases use domain-specific compact arrays plus spatial indexes; chapter defines generic container hooks only, domain schema comes later.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.
