======================================================================
PUBLIC CONTRACTS
======================================================================
1. Jolt lifecycle RegisterDefaultAllocator/Factory/RegisterTypes is process-level backend bootstrap owned by PhysicsService, not arbitrary modules.

2. Genomes uses SI units, right-handed Y-up matching engine semantic convention; transform conversion is explicit tested wrapper.

3. Broadphase/object layers separate StaticWorld, Dynamic, Character, Debris, Sensor and optional ProjectileQuery according interaction matrix.

4. PhysicsSystem Update uses fixed 1/60 simulation step from SimulationClock; render frame delta is never passed directly.
