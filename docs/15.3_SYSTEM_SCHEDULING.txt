PUBLIC CONTRACTS
======================================================================
1. SystemDescriptor declares stable SystemId, phase, required query, component Reads/Writes, external resource Reads/Writes, cadence policy and explicit before/after only when data declaration cannot express relation.

2. Phases baseline: InputCommands, Sense, Decide, Navigate, MoveIntent, PhysicsCommands, PhysicsStep, Combat/Ballistics, Damage/Destruction, Commit, PresentationExtract. Domain systems register into appropriate phase later.

3. Scheduler creates edge when write/read or write/write hazard exists on overlapping resource/component plus phase order; independent systems/chunks can run parallel.

4. System callback receives SystemContext with tick, fixed dt, ECS read snapshot/chunk task, command/event writers and services explicitly declared.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define resource access keys and SystemDescriptor validation.

STEP 2
    Build dependency DAG at bootstrap/freeze; reject cycles with readable chain.

STEP 3
    Within system, partition matching ECS chunks into jobs when estimated rows > grain; system completion handle satisfies outgoing dependencies.

STEP 4
    Allow explicit serial/main-thread systems only by flag with documented reason.

STEP 5
    Add graph dump and runtime timing metrics by SystemId.

STEP 6
    Test artificial read/write graphs and parallel independent systems.

======================================================================
PSEUDOCODE
======================================================================
BUILD GRAPH:
    for systems A,B:
        if phase(A)<phase(B): possible ordered edge by phase barrier policy
        if overlap and (A writes resource read/written by B):
            edge according stable phase/system order
    add explicit before/after
    topo sort/reject cycle

RUN TICK:
    for ready systems:
        schedule chunk jobs
        systemHandle := whenAll(chunkJobs)
        release dependent systems on complete

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Scheduler owns system DAG. Systems never spawn unmanaged threads. Chunk write exclusivity derived from access declaration.

======================================================================
ERROR HANDLING
======================================================================
Invalid/stale entity handles and illegal structural mutation return typed errors or development assertions; expected gameplay failures are not exceptions.

======================================================================
DETERMINISM RULES
======================================================================
System dependency order stable. Parallel independent systems must use command buffers/stable commit for cross-entity effects.

======================================================================
PERFORMANCE RULES
======================================================================
Avoid global barrier between every system if DAG permits overlap; coarse phases only where external backend requires it.

======================================================================
MIGRATION / COMPATIBILITY

SOURCE object model remains reference behavior only; TARGET does not preserve object hierarchy when data-oriented behavior is equivalent.
