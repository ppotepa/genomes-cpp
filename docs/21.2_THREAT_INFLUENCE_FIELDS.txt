======================================================================
PUBLIC CONTRACTS
======================================================================
1. Field source points are derived from faction-known observations/signals/orders with confidence/timestamps; unknown enemy entities are never injected directly into player/faction threat atlas.

2. Kernel definitions are explicit/versioned: radial/anisotropic influence, decay, terrain/cover modifiers where used. CPU reference defines semantic expected result.

3. Multiple source accumulation uses deterministic or tolerance-bounded reduction; if GPU float atomic order differs, field remains advisory.

4. Field revision records source observation snapshot tick and world field revisions.

5. AI consuming field treats it as heuristic/cost input, never direct target visibility.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Define source extraction from known contacts and friendly forces.

STEP 2
    Implement CPU raster kernel reference with bounded support radius.

STEP 3
    Implement GPU tiled dispatch accumulating sources via binning per tile or source lists, avoiding every-cell×every-source brute force.

STEP 4
    Add temporal decay/update strategy based on source tick/confidence.

STEP 5
    Integrate field handle/revision into tactical AI observation as optional heuristic.

STEP 6
    Compare CPU/GPU on small deterministic maps with tolerance and benchmark large fields.

======================================================================
PSEUDOCODE
======================================================================
SOURCE VALUE:
    d := distance(cellCenter, source.pos)
    if d >= source.radius: 0
    t := 1 - d/source.radius
    value := source.strength * source.confidence * smoothstep01(t)
    optional anisotropy := f(dot(direction,source.forward))

TILED:
    bin sources to overlapping atlas tiles
    for dirty tile dispatch workgroup:
        for cell:
            sum := 0
            for source in tileSourceList:
                sum += contribution
            output[cell] := decay(previous)+sum

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
CPU source extraction from committed shared-state snapshot. GPU work asynchronous; AI uses last completed compatible revision.

======================================================================
ERROR HANDLING
======================================================================
No field available -> AI fallback to direct/local logic. Stale beyond policy age -> ignore/downweight.

======================================================================
DETERMINISM RULES
======================================================================
CPU reference deterministic. GPU tolerance only; never use floating GPU sum as decisive authoritative event.

======================================================================
PERFORMANCE RULES
======================================================================
Spatial source binning mandatory for many sources. Measure dispatch, source binning, dirty tiles and overlap with graphics.
