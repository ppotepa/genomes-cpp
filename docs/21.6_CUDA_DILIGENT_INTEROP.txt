PUBLIC CONTRACTS
======================================================================
1. Interop only enabled when CUDA device matches render physical device using robust identifier (UUID/LUID as platform/API supports).

2. The capability contract accepts shared buffers/images only when both sides advertise export/import support, a supported opaque handle transport, and a supported resource type/format.  Native D3D12/Vulkan creation and CUDA import remain adapter responsibilities.

3. Synchronization uses imported external semaphores/fences/timeline where supported; ownership/order is explicit. No CPU busy wait.

4. Diligent/native handle escape is confined to DiligentNativeInterop backend file; generic render/compute APIs remain handle-based.

5. Unsupported backend/driver/resource format automatically falls back to normal Diligent compute or copy path.

PSEUDOCODE
======================================================================
CREATE INTEROP BUFFER:
    renderNative := createExportableBuffer(size,usage)
    externalHandle := exportMemoryHandle(renderNative)
    cudaMem := cudaImportExternalMemory(externalHandle,size)
    cudaPtr := map(cudaMem)
    semRenderToCuda := export/import semaphore
    semCudaToRender := export/import semaphore

CUDA PASS:
    renderQueue.signal(renderToCuda, value)
    cudaStream.waitExternal(renderToCuda,value)
    launch(cudaPtr)
    cudaStream.signalExternal(cudaToRender,value2)
    renderQueue.wait(cudaToRender,value2)

DESTROY:
    ensure outstanding waits/signals complete
    destroy cuda semaphores/memory mappings
    close OS handles per ownership rules
    release render resource

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
External synchronization values centrally owned per interop resource. Native queue submission respects Diligent/backend thread rules.

======================================================================
ERROR HANDLING
======================================================================
Any import/device mismatch -> disable interop for resource/backend and fallback. Partial imports cleaned transactionally.

======================================================================
DETERMINISM RULES
======================================================================
Interop only changes transport/scheduling, not kernel semantics.

======================================================================
PERFORMANCE RULES
======================================================================
Accept only when copy/stall reduction improves total frame/workload. Monitor overlap contention with graphics.
