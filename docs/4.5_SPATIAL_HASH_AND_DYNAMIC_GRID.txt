PUBLIC CONTRACTS
======================================================================
1. cell coordinate uses floor((p-origin)/cellSize), never truncation.

2. Entries are handles/IDs, not pointers. Update removes old covered cells and inserts new cells using cached cell range.

3. Query writes into caller-provided scratch/output buffer and deduplicates IDs without global allocations.

4. DynamicGrid update may be parallelized by staging per-job cell commands and deterministic/partitioned merge; no concurrent mutation of unordered buckets in first implementation.

PSEUDOCODE
======================================================================
INSERT(id,bounds):
    range := cellsOverlapped(bounds)
    for cell in range:
        buckets[cell].push(id)
    entryRange[id] := range

QUERY(bounds,out,scratch):
    stamp := scratch.nextStamp()
    for cell in cellsOverlapped(bounds):
        for id in buckets[cell]:
            if scratch.markFirst(id,stamp):
                out.push(id)
