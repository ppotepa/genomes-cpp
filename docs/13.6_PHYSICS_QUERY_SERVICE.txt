======================================================================
PUBLIC CONTRACTS
======================================================================
1. Query types RayCast, SegmentCast, ShapeCast, OverlapAabb/Shape. QueryFilter has layer mask, ignore body/semantic IDs and optional predicate executed after broadphase hit mapping.

2. Hit record: fraction/distance, point, normal, PhysicsBodyHandle, semantic ID, material/surface tag, subshape/structural ID optional. No Jolt pointer escapes.

3. Batch query API accepts spans and per-job output/scratch; queries are scheduled only in a phase safe relative to PhysicsSystem::Update unless backend provides documented concurrent query snapshot.

4. WorldQuery may choose terrain semantic direct sample instead of physics ray where appropriate.

======================================================================
DATA LAYOUT
======================================================================
Public physics handles/recipes are Genomes-owned. Jolt BodyID/ShapeRef are backend-private mappings.

======================================================================
PSEUDOCODE
======================================================================
BATCH:
    require phase == QuerySafe
    parallelFor query ranges:
        for q:
            joltCollector := execute backend query
            for hit:
                map BodyID -> PhysicsBodyHandle/semanticId
                apply post filter
                write caller output
            optional sort by fraction then semanticId

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Queries may run concurrently only according to Jolt documented safe access phase. Do not run while Update locks world unless explicitly proven supported. Outputs are job-local.

======================================================================
ERROR HANDLING
======================================================================
Backend errors map to typed PhysicsError/diagnostics. Failed body creation or step does not leave half-registered public handles.

======================================================================
DETERMINISM RULES
======================================================================
Closest hit fraction defines result; equal-fraction tie uses stable semantic ID if deterministic ordering requested.

======================================================================
PERFORMANCE RULES
======================================================================
Batch thousands of queries, reuse collectors/scratch, layer filters before narrow phase, benchmark 1k/100k rays.
