PUBLIC CONTRACTS
======================================================================
1. Parity fixture groups: material assemblies/layers, local DamageField/hole, structural support cascades, building adapter full target, hero/cheap/baked accounting, rubble field operations, blast geometry effects, lifecycle/dispose.

2. Conservation hard invariant: for collapse-only material transfer, source detached solid volume ~= hero + cheap + baked + explicitly removed/excavated/unrepresented categories, with every nonconserved category separately accounted. No unexplained loss.

3. SOURCE tests are mapped individually: destruction_core, building_destruction_v6, building_damage_chunks/lazy/quality, destruction_rubble/spatial/lifecycle/effects. Each has native test/report counterpart.

4. Numerical parity tolerances are explicit per material/work/damage field. Visual effect differences are P4 and never substitute semantic parity.
