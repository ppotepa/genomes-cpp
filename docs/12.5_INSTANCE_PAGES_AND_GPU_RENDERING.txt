======================================================================
PUBLIC CONTRACTS
======================================================================
1. InstancePage groups RegionId + prototype/variant + render material family and stores SoA transform/scale/flags plus aggregate bounds. Pages are sized for culling/streaming budget, not one giant world buffer.

2. All LOD meshes for page share one logical instance transform table; LOD selection chooses mesh representation without duplicate CPU transforms.

3. Wind/season visual parameters are material/global/instance fields and must not reroll geometry identity.

4. Far vegetation may use impostor/billboard later; initial mesh LOD path remains extensible.

======================================================================
DATA LAYOUT
======================================================================
CPU instance page:
    page ID / region / prototype ID
    contiguous transforms
    compact per-instance variation values
    world bounds
    semantic revision
    resident/dirty ranges

GPU representation:
    instance buffer handles
    visibility/LOD compacted buffers
    indirect command ranges
    page generation/revision

GPU buffers are renderer-owned derivatives. Semantic VegetationInstance pages
remain CPU/world data and can be recompiled without changing instance identity.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Partition EnvironmentLayout into page size/spatial chunks and stable order.

STEP 2
    Upload one transform/instance record set per page to GPUScene; share across prototype LOD meshes.

STEP 3
    Register prototype mesh/material tables and page aggregate bounds.

STEP 4
    Integrate GPU culling/LOD thresholds with hysteresis.

STEP 5
    Add foliage shadow policy by LOD/profile without semantic effect.

STEP 6
    Benchmark 100k/1M instances CPU submission, VRAM and GPU culling.

======================================================================
PSEUDOCODE
======================================================================
COMPILE:
    groups := group instances by region/prototype/pageCell
    for group:
        page.transforms := SoA stable sorted by InstanceId
        page.bounds := merge prototype bounds transformed
        gpuPage := gpuScene.upload(page)
        register LOD mesh table(prototypeId,gpuPage)

CULL:
    per page coarse bound
    then per instance GPU culling/LOD as policy

THREADING / OWNERSHIP RULES
======================================================================
CPU page compile jobs independent. GPU uploads staged; region unload deferred-release safe.
