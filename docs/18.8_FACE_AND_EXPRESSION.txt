======================================================================
PUBLIC CONTRACTS
======================================================================
1. Face identity/neutral baseline belongs to phenotype/genome. Runtime FaceState contains expression weights, gaze target, blink/saccade timers and smoothing state; it never mutates genome.

2. SOURCE face-expression-1.1.0 compatibility uses one sequential
LegacyMulberry32(uint32(seed XOR 0x9e3779b9)) stream, consumed by blink,
attention and saccade scheduling.

TARGET may introduce dedicated event-indexed substreams because they are more
robust under variable cadence/sleep, but this MUST be a new face-animation
algorithm version. It must not be reported as exact SOURCE random-sequence
parity.

3. Output is PoseDelta/FacialChannels: bone/controller rotations plus morph weights eyelidsClose/eyelidsArc and other explicitly supported channels; no direct mesh mutation.

4. World look target converts through entity/root transform snapshot with bounded yaw/pitch/eye limits; missing target resumes deterministic idle gaze.

5. Animation cadence may skip expensive settled spring integration only when mathematically equivalent timers/event boundaries are preserved.

======================================================================
DATA LAYOUT

PSEUDOCODE
======================================================================
SOURCE COMPATIBILITY EVENT STREAM:
    random := LegacyMulberry32(unitSeed XOR 0x9e3779b9)
    // Preserve SOURCE call order for face-expression-1.1.0 fixtures.
    nextBlink := sourceRandomBlinkDelay(random, phenotype)
    nextAttention := .55 + random.next()*1.15
    nextSaccade := sourceRandomSaccadeDelay(random, phenotype)
    subsequent events consume the same sequential stream as SOURCE.

NATIVE VERSIONED EVENT STREAM (new algorithm version only):
    stream := SeedTree(unitSeed).child("face/events")
    eventValue := stream.event(stableEventKind,eventIndex)
    // cadence/sleep-independent, but not exact legacy sequence

EXPRESSION:
    target[channel] := neutral[channel]
    for expression in requestedWeights stable enum order:
        target += profile[expression][channel] * weight
    clamp semantic channels
    spring(state.channel, target, omega, dt)

LOOK:
    localTarget := inverse(rootTransform) * worldTarget
    yaw,pitch := directionAngles(localTarget)
    clamp to phenotype/profile bounds
    distribute head/eyes/brows per profile

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Face evaluation pure/entity-local given immutable profiles/pose root. Parallel chunks. No shared RNG object.

======================================================================
ERROR HANDLING
======================================================================
Nonfinite target/weights rejected or sanitized at intent boundary with diagnostics. Missing channel/morph in appearance artifact is compile/validation mismatch.

======================================================================
DETERMINISM RULES
======================================================================
Compatibility version preserves SOURCE sequential stream/call order exactly.
Its cadence optimization must not skip RNG-consuming event transitions.

A newer version may use event-indexed RNG to make cadence/sleep independent.
Same version + ticks/intents must produce stable channels, and version must be
part of artifact/state/parity metadata.

======================================================================
PERFORMANCE RULES
======================================================================
Variable cadence for distant presentation. Settled channel early-out. No geometry rebuild. Benchmark 10k face states at 5/15/60Hz tiers.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Preserve SOURCE expression labels/behavior and selected fixture outputs; renderer morph application belongs presentation.
