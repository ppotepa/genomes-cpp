======================================================================
PUBLIC CONTRACTS
======================================================================
1. StrategicGraph nodes represent region gateways/major road junction clusters/important indoor-world portals; edges carry distance/time/terrain/road-class/capability cost.

2. Long path result = ordered RegionIds + strategic corridor/gateway sequence, not low-level points.

3. Agent/group capability determines edge filter: road-required vehicle, foot off-road capability, bridge restrictions etc.

4. Strategic A* heuristic admissible from world distance * minimum travel cost.

======================================================================

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Build/update StrategicGraph from loaded/generated region metadata/road gateway artifacts, including unloaded region metadata where route planning allowed.

STEP 2
    Implement stable A* tie by node ID and area/capability filter.

STEP 3
    Convert strategic result into NavCorridorHint containing region/tile/road bands for local planner.

STEP 4
    Cache route skeleton by start strategic node/end/capability/world road revision.

STEP 5
    Invalidate cache only when relevant road/region connectivity revisions change.

STEP 6
    Benchmark continent/large map synthetic graphs.

======================================================================
PSEUDOCODE
======================================================================
STRATEGIC PATH:
    startNode := nearest strategic gateway(start)
    goalNode := nearest strategic gateway(goal)
    route := A*(graph, costByCapability)
    return Corridor{
        regions = edges->regions,
        gateways = route nodes,
        roadEdges = preferred major edges
    }

LOCAL:
    for corridor segment:
        request Detour path constrained/biased to corridor tiles
