======================================================================
PUBLIC CONTRACTS
======================================================================
1. WorldQuery terrain height/normal reads HeightFieldArtifact directly for cheap samples; physics collision is separate compiled representation for dynamic bodies.

2. Physics recipe stores dimensions/cell size/heights or backend-neutral heightfield ref, not Jolt objects.

3. Terrain modifications invalidate affected physics/nav tiles by bounds/revision; entire world is not rebuilt.

======================================================================
DATA LAYOUT
======================================================================
One authoritative HeightFieldArtifact backs both sampling and representation
compilers.

Query representation:
    HeightQueryGrid
        shared immutable height span/reference
        origin
        sample spacing
        width/height
        revision

Physics representation:
    TerrainCollisionTileRecipe[]
        tile bounds
        sample range/height span
        collision material IDs
        revision

PhysicsBody/Shape handles live in engine/physics backend state, not terrain
semantic records. Query interpolation reads the authoritative modified height
field so road/pad grading cannot diverge from collision/query height.

======================================================================
PSEUDOCODE
======================================================================
APPLY PATCH:
    newArtifact := compile(base,patch)
    dirtyBounds := patch.bounds expanded by normal/collision margin
    emit TerrainChanged(region,oldRevision,newRevision,dirtyBounds)
    physics.enqueueRebuild(dirtyBounds)
    nav.enqueueDirty(dirtyBounds)

THREADING / OWNERSHIP RULES
======================================================================
Queries read immutable height artifacts; physics recipe rebuild jobs read same artifact revision.

======================================================================
ERROR HANDLING

======================================================================
DETERMINISM RULES
======================================================================
Terrain query results tied to artifact revision, not physics simulation timing.
