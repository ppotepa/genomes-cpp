======================================================================
PUBLIC CONTRACTS
======================================================================
1. NavDirtyBounds event includes world bounds, reason/source semantic ID, world revision and affected AgentProfile mask.

2. Dirty bounds maps to overlapping nav tiles plus configured border. Multiple events coalesce per tile before rebuild; high-frequency damage debounce has maximum latency bound.

3. Rebuild job reads latest immutable world/structure revision; commit checks generation token. Old tile stays queryable until replacement ready, then atomic owner swap increments nav revision.

4. Path/shared-path results carrying old nav revision are marked potentially stale; policy can continue until obstacle check or request replan.

======================================================================
PSEUDOCODE
======================================================================
DIRTY(event):
    for tile overlap(event.bounds expanded):
        entry := dirty[tile,profile]
        entry.bounds.union(event.bounds)
        entry.generation += 1

REBUILD(entry,gen):
    source := acquire latest region snapshot
    artifact := buildTile(source)
    commit:
        if gen != dirty.entry.generation: discard/rebuild latest
        swap Detour tile old->new
        navRevision++
        clear entry
        invalidate paths intersecting tile

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Build jobs parallel, backend tile swap serialized. Old tile remains live until safe swap.

======================================================================
ERROR HANDLING
======================================================================
Path requests return typed status Success/Partial/NoPath/Unloaded/Cancelled/Invalid and never fabricate a route through unknown regions.

======================================================================
DETERMINISM RULES
======================================================================
Event coalescing timing may affect when tile updates but resulting tile for same source revision/config deterministic.

======================================================================
PERFORMANCE RULES
======================================================================
Localized tiles, debounce, priority/budget. Never rebuild entire map from one wall.
