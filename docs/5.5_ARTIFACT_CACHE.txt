======================================================================
PUBLIC CONTRACTS
======================================================================
1. CacheKey includes artifact type, generator ID/version, schema version, normalized input fingerprint, sorted dependency fingerprints, seed derivation version and relevant build/platform recipe version only when output truly platform-dependent.

2. Select BLAKE3 as canonical content fingerprint if dependency/license review passes; otherwise use another explicitly versioned >=128-bit content hash. StableHash64 is not sufficient as sole artifact integrity key.

3. In-memory cache has byte budget + LRU/clock eviction; pinned/in-use artifacts are not evicted. Disk cache format uses atomic temp-write + rename and validates header/fingerprint before publish.

4. Cache miss/failure is not generator failure: regenerate unless artifact is explicitly required offline.

======================================================================
DATA LAYOUT
======================================================================
Use explicit versioned value types and ownership. Hot data remains contiguous; cold metadata is separate.

STEP 2

STEP 3
    Implement memory cache with retainedBytes accounting, hit/miss/evict metrics and explicit pin/view lifetime.

STEP 4
    Implement disk-cache interface and file naming by fingerprint; disk backend may be minimal but atomicity/checksum tests required.

STEP 5
    Reject artifact whose recomputed fingerprint mismatches header.

STEP 6
    Implement version namespace so generator/schema changes cannot accidentally reuse old cache.

STEP 7
    Benchmark 100k key lookups, LRU churn and disk metadata scan separately.

PSEUDOCODE
======================================================================
LOOKUP(key):
    fp := contentHash(canonicalEncode(key))
    if memory.contains(fp):
        touchLRU(fp); return hit
    if disk.enabled:
        bytes := disk.read(fp)
        if validateHeaderAndHash(bytes):
            artifact := deserialize(bytes)
            memory.insert(fp, artifact)
            return hit
    return miss

STORE:
    bytes := canonicalSerialize(artifact)
    fp := contentHash(bytes.payload)
    write temp
    fsync/close according policy
    atomicRename(temp, final)
    memory.insert(fp, artifact)
    evictUntilWithinBudget()
