======================================================================
PUBLIC CONTRACTS
======================================================================
1. Retirement is per subsystem/path category, never blanket "native exists so legacy deleted".

2. Statuses: ACTIVE_SOURCE_REQUIRED, FIXTURE_EXPORTER, REFERENCE_LAB, HISTORICAL_DOC, RETIREABLE_SHIPPING_PATH, DO_NOT_DELETE_EVIDENCE.

3. A subsystem can be RETIREABLE only if owning native parity chapter PASS, native dependents no longer require SOURCE runtime, native debug/acceptance route exists and fixture provenance is preserved.

4. SOURCE prototypes may remain permanently as lightweight algorithm labs even after shipping path retired.

5. No deletion of legacy tests/research fixtures that are sole evidence for behavior; convert/export before any cleanup.

        status := DO_NOT_DELETE_EVIDENCE
    else if row.uniqueLabValue and nativeViewerNotEquivalent:
        status := REFERENCE_LAB
    else if row.usedToRegenerateFixtures:
        status := FIXTURE_EXPORTER
