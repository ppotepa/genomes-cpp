REFERENCE_LAB, RESEARCH_DOCUMENT, REDUNDANT_EVIDENCE or DO_NOT_DELETE_EVIDENCE.

2. No TARGET runtime module may depend on SOURCE. Exporters are development
tools only; the TARGET validation suite remains runnable without SOURCE access.

5. External repository cleanup is a separate reviewed task and is never implied
by completion of this chapter.
