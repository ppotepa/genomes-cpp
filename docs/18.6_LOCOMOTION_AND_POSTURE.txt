PUBLIC CONTRACTS
======================================================================
1. LocomotionState separates requestedCrouch/requestedSpeedMps from actual constrained values, target speed/runWeight/sprintWeight, phase and limitReason.

2. BIPED family presets map to requested values but changing among IDLE/WALK/RUN/CROUCH/CROUCH_WALK does not reset gait phase. PRONE/SEATED/REST remain explicit families.

3. All finite zero values are valid. NaN/Infinity rejected. Clamp to phenotype-specific limits after validation.

4. PostureProfile is continuous/monotonic between authored key profiles with explicit interpolation formula; it outputs normalized/metric pose parameters, not renderer bone objects.

5. Simulation locomotion/world movement and visual pose phase are separable; treadmill preview is presentation only.

======================================================================
PSEUDOCODE
======================================================================
SET:
    if crouch provided:
        require finite
        requestedCrouch := clamp(crouch,0,1)
    if speed provided:
        require finite
        requestedSpeed := clamp(speed,0, phenotype.runSpeed)

STEP:
    maxCrouch, reason := solveLimit(phenotype, mode, requestedSpeed)
    targetCrouch := min(requestedCrouch,maxCrouch)
    actualCrouch := approach(actualCrouch,targetCrouch,dt)
    targetSpeed := solveSpeed(requestedSpeed, actualCrouch, phenotype)
    actualSpeed := approach(actualSpeed,targetSpeed,dt)
    if mode is BIPED:
        phase += actualSpeed / cycleLength(actualCrouch,runWeight) * dt
        phase := fract(phase)

POSE PARAMETERS:
    profile := postureCurve.sample(actualCrouch)
    blend walk/run gait by runWeight without resetting phase
