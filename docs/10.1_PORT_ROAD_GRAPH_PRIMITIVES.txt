PUBLIC CONTRACTS
======================================================================
1. RoadNode has stable RoadNodeId, XZ position + sampled height/ref, node type, region lineage. RoadEdge has stable RoadEdgeId, endpoints, RoadClass, surface, width/ROW, speed/capacity, bridge/tunnel level, lineage/seed metadata.

2. Graph mutation occurs only during candidate generation. Published RoadGraphArtifact is immutable.

3. splitEdge(eid,p) retires original edge in build graph and creates deterministic child IDs derived from parent ID + split ordinal/quantized semantic point key.

4. Adjacency arrays/indices support degree/other/endpoints without per-edge heap sets in published artifact.

PSEUDOCODE
======================================================================
ADD EDGE:
    require a != b
    if adjacency contains same endpoint pair + semantic lane/level key:
        return Existing
    id := deriveEdgeId(seed,parent,lineageOrdinal)
    append edge
    adjacencyBuild[a].push(id)
    adjacencyBuild[b].push(id)

SPLIT:
    old := edge[eid]
    deactivate old
    n := addNode(point, Junction)
    e1 := addEdge(old.a,n,copyMetadata(old), child=0)
    e2 := addEdge(n,old.b,copyMetadata(old), child=1)
    return n,e1,e2
