======================================================================
PUBLIC CONTRACTS
======================================================================
1. RegionCollisionArtifact groups terrain heightfield shape recipe + building/static shapes with stable semantic IDs and collision chunks.

2. Static Jolt bodies/shapes created on physics owner command phase and mapped to RegionId/chunk. Region unload removes bodies only after no dynamic references/query snapshots depend on them.

3. Large static geometry partitioned by region/chunk to support broadphase and localized rebuild; no single world-wide triangle mesh.

4. Terrain uses HeightFieldShape where suitable; buildings use box/convex/mesh recipes from compiler with material/user data mapping.

======================================================================
DATA LAYOUT
======================================================================
Public physics handles/recipes are Genomes-owned. Jolt BodyID/ShapeRef are backend-private mappings.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement RegionCollisionLoader that converts backend-neutral recipes to cached Jolt Shapes off-step where thread-safe, then enqueues body add commands.

STEP 2
    Map stable semantic IDs to Body user data table without stuffing raw pointers.

STEP 3
    Implement stream-in commit and stream-out command with generation token.

STEP 4
    Implement localized dirty chunk rebuild for TerrainChanged/BuildingChanged events.

STEP 5
    Test adjacent region seams and dynamic body crossing while neighbor streams in/out under pin policy.

======================================================================
PSEUDOCODE
======================================================================
LOAD REGION:
    recipes := region.physicsArtifact
    shapes := parallelCompileShapes(recipes)
    commandBuffer.add:
        create static bodies for chunks
        attach semanticId mapping
    after step commit residency Physics=true

DIRTY CHUNK:
    build replacement shape
    preStep:
        remove old body
        add replacement at same semantic mapping
        increment collision revision

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
Jolt body add/remove only outside active Update via physics owner. Shape creation may parallelize if allowed by backend and immutable inputs.

======================================================================
ERROR HANDLING
======================================================================
Backend errors map to typed PhysicsError/diagnostics. Failed body creation or step does not leave half-registered public handles.

======================================================================
DETERMINISM RULES
======================================================================
Static body IDs backend-private; semantic mapping stable. Streaming timing does not change world semantics beyond explicitly unloaded query completeness.

======================================================================
PERFORMANCE RULES
======================================================================
Chunk shapes, sleeping dynamic bodies, broadphase static layer. Avoid one body per wall where compound/chunk cheaper and damage policy allows.

======================================================================
MIGRATION / COMPATIBILITY
======================================================================
Replaces SOURCE Rapier static maps/building proxies after building/destruction parity.
