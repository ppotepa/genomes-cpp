PUBLIC CONTRACTS
======================================================================
1. JobSystem owns N worker threads plus external submitters. Default worker count = max(1, hardware_concurrency - reservedMainThreads) with explicit override for tests.

2. Job is a small move-only callable or function pointer + context; scheduling metadata is separate from domain data.

3. JobHandle identifies completion state and can be waited from external thread. Worker waits must execute/assist runnable jobs rather than block when safe.

4. JobContext exposes worker-local ScratchContext, worker index for diagnostics only, cancellation query placeholder, and JobSystem reference.

5. Shutdown has Drain and CancelPending modes with deterministic lifetime semantics.

======================================================================
DATA LAYOUT
======================================================================
Use compact value types, explicit ownership, contiguous storage in hot paths, and no hidden shared mutable state.

IMPLEMENTATION STEPS
======================================================================
STEP 1
    Implement worker pool with one global concurrent injection queue initially; work-stealing deques arrive in 3.2.

STEP 2
    Use condition_variable/semaphore to sleep idle workers; no spin loop when idle.

STEP 3
    Implement submit returning JobHandle backed by ref-counted/internal completion node owned by scheduler, not shared_ptr in hot domain data.

STEP 4
    Implement wait(handle): external waiter blocks; worker waiter assists executeOne until handle completes.

STEP 5
    Implement fence/counter primitive for multiple jobs.

STEP 6
    Implement clean shutdown and tests for jobs completing before destruction.

STEP 7
    Add benchmark for submit+execute throughput at 1/2/4/... workers.

======================================================================
PSEUDOCODE
======================================================================
WORKER LOOP:
    while running:
        if tryPopGlobal(job):
            execute(job)
            complete(job)
            continue
        sleepUntilWorkOrShutdown()

SUBMIT:
    node := allocateJobNode()
    node.pending := 1
    enqueueGlobal(node)
    wakeOneWorker()
    return handle(node)

WAIT:
    if callerIsWorker:
        while !handle.complete:
            if !executeOneRunnable():
                shortWait()
    else:
        handle.waitCondition()

======================================================================
THREADING / OWNERSHIP RULES
======================================================================
    - Ownership is explicit.
    - Public APIs do not hide global mutable state.
    - Thread safety is documented per type.
    - Cross-thread mutation uses later JobSystem/command-buffer contracts where applicable.

======================================================================
ERROR HANDLING
======================================================================
Expected failures return Result/typed errors. Programmer-contract violations use diagnostics/assertion policy. No exception-driven hot-path control flow.

======================================================================
DETERMINISM RULES
======================================================================
Deterministic output must not depend on pointer values, hash-map iteration order, thread completion order, wall time, or platform-dependent representations.

======================================================================
PERFORMANCE RULES
======================================================================
